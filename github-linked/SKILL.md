# 사주 전문가 스킬 (GitHub 실시간 연동판)

이 파일은 **로더(loader)**다. 분석 절차는 저장소의 원본 `SKILL.md`에 있고, 이 파일은 그것을 어디서 어떻게 읽는지만 정한다.
절차를 여기에 요약해 두지 않는다 — 요약이 원본과 어긋나는 일이 반복됐기 때문이다(`references/00_errata.md`).

---

## 1. 데이터 소스

- **저장소**: `dlwjdgh95-byte/SAJU`
- **ref**: `main` (병합된 최신본). 특정 시점으로 고정하고 싶으면 저장소에 태그를 만들고 그 이름을 ref로 쓴다.
- **경로**: 원본 절차 `SKILL.md`, 상세 자료 `references/<파일명>`, 계산 `scripts/saju_calc.py`

### 읽는 방법 (우선순위)

1. **GitHub 커넥터 (권장)**: 연결돼 있으면 커넥터로 저장소의 해당 경로를 읽는다. 비공개 저장소도 이 방식으로 접근된다.
2. **raw URL (공개 저장소일 때)**: `https://raw.githubusercontent.com/dlwjdgh95-byte/SAJU/main/<경로>`

---

## 2. 시작 절차

```
① 원본 SKILL.md를 읽는다. 그 문서의 「회귀 방지 규칙」·「라우팅 맵」·Step 0~9를 그대로 따른다.
② 원본이 references/… 파일을 읽으라고 하는 단계마다 그 파일을 GitHub에서 읽는다.
   암기·추측으로 대신하지 않는다. 원전 근거·평어·세부 규칙은 항상 파일에서 가져온다.
③ 계산은 scripts/saju_calc.py를 가져와 실행한다 (아래 3).
④ 이 로더와 원본 SKILL.md가 다르면 원본이 정본이다.
```

---

## 3. 계산 스크립트

코드 실행이 가능하면 스크립트를 내려받아 실행한다. 산문 공식으로 암산하지 않는다.

```bash
curl -sSLO https://raw.githubusercontent.com/dlwjdgh95-byte/SAJU/main/scripts/saju_calc.py
pip install ephem korean-lunar-calendar --break-system-packages   # 최초 1회
python3 saju_calc.py --birth "1995-10-29 06:30" --gender M
python3 saju_calc.py --pillars "乙亥 丙戌 癸巳 乙卯"
```

커넥터로만 읽을 수 있으면 파일 내용을 그대로 저장해 실행한다. 옵션과 출력 확인 항목은 원본 SKILL.md Step 1에 있다.
코드 실행이 불가능한 환경이면 `references/26_manual_calc.md`로 수동 계산한다.

## 4. 저장소를 읽을 수 없을 때

커넥터도 raw URL도 실패하면 분석을 진행하지 말고 사용자에게 알린다.
일반 명리 지식으로 대신 답할 때는 이 스킬의 자료와 계산을 쓰지 못했다는 점을 먼저 밝힌다.
