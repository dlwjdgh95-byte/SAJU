## 1. 이 문서의 위치 — 저장소에서 근거가 가장 얇은 층위다

```
⚠️ 인연법은 학파 편차가 극심하다. 용신법·일지대조법·공망인연법·일주대조법·납음법이

   이 문서는 저장소가 이미 지지하는 축에서만 유도하며, 축별 등급을 반드시 병기한다.
```

| 축 | 등급 | 근거 |
|---|---|---|
| **① 용신 보충** | **A** | 격국·조후 판정과 직결. 이 문서의 주축 |
| **② 배우자궁(일지)** | **B** | 궁위론. `29_sibisinsal.md` §4 자리별 독법과 동일 층위 |

| ④ 재성=배우자 매핑 | **B** | 고전의 전제. 남명 재성/여명 관성. 궁위·용신과 **함께** 읽고 단독으로 쓰지 않는다 |
| ⑤ 띠(년지) 단독 대조 | **C~D** | 8자 중 1자. 주축으로 쓰지 않는다. 대중 인연법 대부분이 여기 머문다 |
| ⑥ 일주 대조·납음·공망인연법 | **C** | 병기만. 단독 서술 금지 |

### 1-1. 절대 금지 (필수)

```
① 사람 판정·배제 금지
   "저 사람은 申이라 안 된다" 식으로 쓰지 않는다. 지지 한 글자는 여덟 중 하나이며,
   상대의 격국·용신·대운이 그 한 글자를 얼마든지 뒤집는다.

② 상대 명조 없이 단정 금지
   본인 명조만으로 나오는 것은 "내 구조에 무리가 적은 방향"까지다.
   궁합 판정은 두 명조를 다 본 뒤에만 가능하며, 그때도 단정하지 않는다.

③ 결혼·이별·재혼 사건 단정 금지
   운은 압력의 방향이지 사건이 아니다. "이 해에 결혼한다/헤어진다"는 서술을 쓰지 않는다.

④ 특정 연도를 "인연이 없는 해"로 선언 금지
   발동이 없다는 것은 그 자리가 조용하다는 뜻이지 인연이 없다는 뜻이 아니다.

⑤ 28_scoring.md 점수 모델에 합산 금지
   인연 층위는 서술 전용이다. 어떤 축에도 점수로 들어가지 않는다.
```

## 2. 구조 규칙 — 최고조와 최저는 항상 짝이다

인종(`32_injong.md`)을 전 일간 × 전 지지로 돌려 확인한 두 규칙이다. **반례 0건.**

### 2-1. 규칙 A — 최고조 조와 최저 조는 항상 극(剋) 관계 (120/120)

어느 지지에서든 최고조인 오행조가 있으면, 그와 **극 관계인 두 조 중 하나**가 최저로 떨어진다.

```
재성↑ → 비겁↓ 또는 인성↓      비겁↑ → 관성↓ 또는 재성↓
관성↑ → 식상↓ 또는 비겁↓      식상↑ → 인성↓ 또는 관성↓
인성↑ → 식상↓ 또는 재성↓
```

### 2-2. 규칙 B — 같은 조의 최고조 지지와 최저 지지는 충(沖) 쌍 (50/50)

각 오행조가 최고조인 두 지지와 최저인 두 지지는 **정확히 충 관계**로 맞물린다.

### 2-3. 인연법에 주는 함의 — 일간별 "재성을 쫓을 때 비는 자리"

재성이 최고조인 지지에서 **무엇이 최저로 떨어지는가**가 일간 오행별로 갈린다.

| 일간 오행 | 재성 왕지 | 그 자리에서 최저 | 실전 함의 |
|---|---|---|---|
| **木**(甲乙) | 巳·午 | **인성** | 재를 쫓으면 **기댈 곳·자격·준비**가 빈다 |
| **火**(丙丁) | 申·酉 | **인성** | 동상 |
| **土**(戊己) | 子·亥 | **비겁 + 인성** | **둘 다 빈다.** 구조적으로 가장 취약 |
| **金**(庚辛) | 寅·卯 | **비겁** | 재를 쫓으면 **체력·동료**가 빈다 |
| **水**(壬癸) | 巳·午 | **비겁** | 동상 |

```
→ 핵심: 재성이 세게 들어오는 시기는 구조적으로 그것을 받을 축이 비는 시기다.
  "인연이 세게 들어오는 때"와 "그것을 감당할 수 있는 때"는 원리적으로 다른 자리다.
  이것이 §4 2축 판정의 근거다.
```

⚠️ **재다신약 명조에서 특히 중요하다.** 재성이 병(病)인 명조는 재성 왕지가 오면
"기회가 커지는 해"가 아니라 "병이 심해지는 해"일 수 있다. `25_byeongyak.md` ③ 재다신약 참조.

## 3. 배우자궁(일지) 독법 — 등급 B

### 3-1. 보는 것

```
① 일지 본기의 십성 — 배우자궁에 무엇이 앉았는가
② 일지 지장간 3자의 십성 — 자리의 질(質). 正(정관·정재·정인)이 많으면 질이 좋다
③ 원국 내 간섭 — 년지·월지·시지가 일지와 어떤 관계인가
   충·형·원진·귀문·해가 걸려 있으면 그 자리가 원국 안에서 이미 시달리고 있다
④ 그 자리가 용신 방향인가 기신 방향인가
```

### 3-2. 해석 규범

- 배우자궁이 **기신 오행**인 경우가 흔하다. 그 자체를 흉으로 읽지 않는다.
  그럴수록 §4의 용신 보충 축이 중요해진다는 뜻이다.
- 원국 내 간섭이 많은 배우자궁은 "관계가 안 된다"가 아니라
  **"그 자리에 원래 긴장이 걸려 있다"**로 읽는다. 운에서 같은 자리가 또 건드려질 때 체감이 커진다.
- 천을귀인이 일지에 있어도 `30_shinsal_extended.md` §3-1 규정대로
  **"결과가 아니라 통로"**다. 문이 열려 있다는 뜻이지 누가 들어온다는 뜻이 아니다.

## 4. 시기 판정 — 2축 (발동 × 수용)

**하나의 점수로 합치지 않는다.** §2-3에서 보듯 두 축은 구조적으로 엇갈리므로, 합산하면 정보가 사라진다.

### 4-1. 축 ① 발동(發動) — 자리가 움직이는가

```
세 가지를 센다:
  ⓐ 일간 천간합 (운 천간이 일간과 합) — 가장 강한 신호. 일간이 직접 묶인다
  ⓑ 배우자궁(일지) 관계 — 육합·삼합/반합·방합 / 충·형·파·해·원진·귀문
  ⓒ 재성 상태 — 인종상 최고조·갈림 / 운 천간이 재성

강(3개 이상) · 중(2개) · 약(1개) · 무(0개)
```

⚠️ **발동은 끌림의 질이 아니라 움직임의 크기다.** 충·형·원진으로 움직이는 것도 발동이다.
발동이 강한 해 = 좋은 해가 아니다. 그 자리가 크게 움직이는 해다.

### 4-2. 축 ② 수용(受容) — 그것을 받을 수 있는가

```
일간 운성의 3상태(32_injong.md §3-1) + 비겁조 슬롯으로 본다.
  활(活) +2 / 전(轉) 0 / 장(藏) −2
  비겁 최고조 +2 · 관리·갈림 +1 · 전환 0 · 창고 −1 · 최저 −2
상(3↑) · 중(0~2) · 하(0 미만)
```

### 4-3. 조합 해석

| | **수용 상** | **수용 중** | **수용 하** |
|---|---|---|---|
| **발동 강** | 맺으면 실질이 되는 국면 (희소) | **인력은 크고 검증은 약해지는 국면** | 눈에 많이 띄나 받지 못하는 국면 |
| **발동 중** | 조용히 진행되는 국면 | 평 | 소모되기 쉬운 국면 |
| **발동 약·무** | **체력이 회복되는 국면** | 평 | 소강 |

```
가장 주의할 칸: 발동 강 × 수용 중·하
  끌림이 크고 판단은 흐려지는 배치다. 이 해가 나쁘다는 뜻이 아니라,
  이 해 안에 끝내려는 결정을 한 박자 늦추는 쪽이 구조에 맞다는 뜻이다.
  "이 해에 만난 인연은 나쁘다"는 단정은 금지한다. (§1-1 ③)

가장 정합한 칸: 발동 중·약 × 수용 상
  압력이 낮고 받을 힘이 있는 자리. 발동이 약하다고 넘기지 않는다.
```

### 4-4. 일간 천간합의 양면성 (필수 병기)

대중 인연법은 일간합을 무조건 길로 읽는다. **그대로 쓰면 틀린다.**

```
일간합 = 일간이 묶인다(羈絆). 길흉은 아래로 따로 판정한다:
  ① 화신(化神) 오행이 그 명조에 용신인가 기신인가
  ② 화신이 왕한 운인가 — 왕하지 않으면 합이불화(合而不化), 묶이되 성질은 안 바뀐다
     (28_scoring.md §2-3의 점화 조건과 같은 층위)
  ③ 방어간(比劫·印星)이 원국·운에 있는가 — 없으면 일간이 단독으로 흡수된다
  ④ 조후 정본이 그 합을 경고하고 있지 않은가
     예) 戌월 癸水의 戊癸합 — 궁통보감이 "수 기능 상실"로 명시 (10번 §戌월)
```

## 5. 친밀·활동 층위 — 제3축 (등급 낮음. 단독 서술 금지)

§4의 두 축은 **"맺어지는가"**를 본다. 이 절은 **"그쪽 에너지가 활발한가"**라는 별개의 질문이다.
두 질문은 자주 엇갈린다. **§4 두 축과 합산하지 않는다.**

### 5-1. ⚠️ 이 절의 등급이 이 문서에서 가장 낮다

| 항목 | 등급 | 근거 |
|---|---|---|
| **도화(桃花)** — 왕지 子午卯酉 | **A~B** | 삼합 구조(생·왕·묘)에서 직접 유도 |
| **진도화 = 년살(年殺)** | **B** | 년지 삼합국 기준 12신살 회전판 위치 (`29_sibisinsal.md`) |
| **식상 상태** | **A(인종) / B(해석 전이)** | 욕구·표출 축. 인종 판정 자체는 A |
| **목욕(沐浴)** | **A(운성) / C(성적 함의)** | 아래 §5-2 — 정본표는 성적 함의로 정의하지 않는다 |
| **홍염살(紅艶)** | **C~D** | `30번` §1: *"근거가 얇다. 조견표도 판본별로 다름"* |
| 음란지합(丁壬合) | **C** | 丁壬합에만 붙는 별칭. 다른 일간에는 해당 없음 |

```
⚠️ C·D 등급은 단독 문장으로 쓰지 않는다. A·B 판단에 곁들이는 부사구로만 쓴다.
   (30_shinsal_extended.md §4 ② 신살 출력 규범)
   → 홍염만 걸린 해를 "그런 해"로 서술하는 것은 규범 위반이다.
```

### 5-2. 목욕(沐浴)을 쓸 때의 필수 고지

`30_shinsal_extended.md` §2-1 정본표는 목욕을 이렇게 정의한다.

> **목욕(沐浴) · 씻고 꾸밈 — 다듬음·치장·변덕. 별칭 패지(敗地) — 방향이 흔들림**

**성적 함의가 아니다.** 목욕을 함지(咸池)·도화와 묶는 것은 **민간 확장**이며, 정본표에 근거가 없다.
이 층위에서 목욕을 쓸 수는 있으나 **반드시 그 사실을 밝히고 쓴다.**
목욕만으로 판정하지 않고, 도화·식상과 겹칠 때만 보조 근거로 쓴다.

### 5-3. 도화의 고전 서술을 옮기지 않는다

도화를 "기생팔자·요물"로 규정한 고전 서술은 **유교 사회의 경계 코드**였다.
현대 상담에 그대로 옮기지 않는다. (`research/blog_underjaw_review.md` §2-1~2-2)
도화의 실질은 **타인의 니즈를 빠르게 읽어내는 감각 / 짧은 시간에 납득되는 선명함**이다.

### 5-4. 활동(活動) 축 판정

```
세 가지가 겹치는 구간을 찾는다:
  ⓐ 식상조 — 인종상 최고조 (욕구·표출의 주력 축, 등급 A)
  ⓑ 도화 계열 — 운 지지가 왕지(子午卯酉), 특히 년지 기준 년살(진도화)
  ⓒ 일간 운성 — 활(活)이면 체력이 받쳐준다. 목욕은 §5-2 고지 후 보조로만

강: ⓐ + (ⓑ 또는 ⓒ 활)  ·  중: 둘 중 하나  ·  약: 없음
```

⚠️ **활동 강 ≠ 좋은 해가 아니다.** 식상 최고조는 설기(洩氣)이기도 하다.
일간이 약한 명조에서 식상 최고조는 **소모가 커지는 구간**이며,
재다신약 명조에서 재성 최고조도 마찬가지다(`25_byeongyak.md` ③).
활동 축과 수용 축을 **반드시 함께** 읽는다.

### 5-5. 명리가 말하지 않는 것 (필수 고지)

```
명리는 성적 빈도를 예측하지 않는다.
말할 수 있는 것: 그쪽으로 관심·에너지가 쏠리는 국면, 관계가 활발해지는 시기
말할 수 없는 것: 실제 빈도 — 상대 유무·건강·생활 여건·일의 밀도가 결정한다

⚠️ "도화가 있으니 관계가 많다 / 없으니 적다"는 서술을 쓰지 않는다.
⚠️ 성적 능력·성향·지향을 판정하지 않는다. 명리에 그 판정 근거가 없다.
⚠️ 건강은 "무리가 누적되기 쉬운 시기" 수준의 생활 조언까지만.
   (31_unse_narrative.md §6 ④ 전문 영역 단정 금지)
```

## 6. 정합 지지 판정 — 상대 지지 후보

### 6-1. 절차

```
① 실질 용신 오행을 먼저 확정한다 (격국·조후·병약. 스크립트가 판정하지 않는다)
② 12지지 각각에 대해:
   - 용신 방향인가
   - 내 일지(배우자궁)와 어떤 관계인가
   - 원국 4지 전체와 긍정/부정 관계가 몇 건인가
③ 용신 방향 ∩ 일지와 긍정 관계 ∩ 부정 관계 최소 → 정합
```

### 6-2. 판정 시 반드시 적용할 보정

| 보정 | 내용 |
|---|---|
| **조토불생금** | 용신이 土여도 **戌·未(조토)는 무효**, 丑·辰(습토)만 유효. 조토 위의 金은 통근처로 세지 않는다 (`25_byeongyak.md`) |
| **무근 용신 고립** | 용신 오행이라도 **원국에 동류가 0개면 허상**일 수 있다. errata #11 — 쇠충왕 자파·상극 용해를 함께 본다 |
| **합보다 충 우선** | 같은 지지에 합과 충이 동시면 충이 우선한다 (`22번` §7 강도 순위: 천간합 ≥ 지지충 > 삼합·방합) |
| **합·형 병존** | 巳申(육합+무은지형+파), 子卯(형), 寅巳(형+해) 등은 **합이 있어도 형·파가 동시**다. "합이니 좋다"로 읽지 않는다 |
| **삼합이 기신을 키우는 경우** | 년지 기준 삼합 짝이 기신 오행을 완성하면 오히려 불리하다. 대중 인연법의 대표 오류 |

### 6-3. "합이면 좋다"의 대표 반례 3종

```
① 일간합인데 일간을 묶는 경우        → §4-4
② 육합인데 형·파가 동시인 경우       → 巳申·寅亥 등
③ 삼합인데 기신 오행을 완성하는 경우  → 원국 식상·재성이 병인데 그 국을 완성
```

## 7. 출력 규범

```
① 축별 등급(§1)을 반드시 병기한다. 띠(년지) 단독 대조를 주축으로 쓰지 않는다.
② 발동과 수용을 분리해 서술한다. 하나의 등급으로 합치지 않는다.
③ 사람 유형이 아니라 **관계 역학**으로 옮긴다.
   "어떤 사람을 만나라"가 아니라 "어떤 역학이 이 구조에 무리가 적은가".
④ 양면 병기. 발동 강에는 위험을, 발동 약에는 회복 기능을 함께 적는다.
⑤ 사건 단정 금지 (§1-1 ③). 시기는 "압력의 방향"까지만 말한다.
⑥ 상대 명조 없이 궁합을 판정하지 않는다. 본인 명조만으로는 "방향"까지다.
⑦ 결정 대행 금지 — 만나라/헤어져라를 말하지 않는다. (`31_unse_narrative.md` §6 ③)
⑧ 마지막에 한계를 명시한다. 이 층위가 저장소에서 가장 얇다는 사실을 숨기지 않는다.
⑨ 친밀·활동 축(§5)을 쓸 때는 등급을 앞세운다. C·D 항목(홍염·음란지합)을 단독으로 쓰지 않고,
   목욕을 쓸 때는 §5-2 고지를 반드시 붙인다. 빈도·성향·능력은 판정하지 않는다.
```

⚠️ `--inyeon-daewoon`을 주지 않으면 **세운 층위만** 본 것이다.
**대운 천간이 일간과 합하는 구간은 10년 내내 그 신호가 깔린다.** 반드시 함께 확인한다.

土를 넣으면 戌·未는 자동으로 `△ 조토 — 실질 무효`로 표기된다.
