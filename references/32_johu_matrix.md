# 32. 조후(調候) 매트릭스 — 기계 판독용 정규화본

> ⚠️ **이 문서는 `01~10번` 궁통보감 원문의 「조후 요약 매트릭스」를 기계가 읽을 수 있게 정규화한 것이다.**
> 해석의 정본은 언제나 원문 파일이다. 이 표는 `28_scoring.md` §2 ②축(조후 18점)을 계산하기 위한 조견표이며,
> 원문의 서술·물상·예외 논의를 대체하지 않는다.

> **읽는 시점**: 운 점수화에서 조후축을 채점할 때. 사람이 조후를 해석할 때는 원문(01~10)을 읽는다.

---

## 1. 표기 규칙

```
천간으로 적힌 것  : 그 천간이 왔을 때 정확히 성립 (예: 丙)
오행으로 적힌 것  : 그 오행이면 성립 (예: 火)
(과다)/(추가)     : 조건부 — 그 기운이 이미 넘칠 때만 기신으로 발동
(소량)            : 적을 때만 희신 — 많으면 오히려 해가 된다
```

### ⚠️ 같은 오행이 용신과 기신 양쪽에 걸리는 칸

120칸 중 **67칸**이 그렇다. 예를 들어 병화 인월은 **임수가 용신인데 계수는 기신**이다 — 둘 다 水다.

그래서 오행만으로 채점하면 절반 이상이 틀린다. 해소 순서는 이렇다.

```
① 천간이 정확히 일치하면 그것을 따른다 (壬은 용신, 癸는 기신)
② 천간이 안 맞으면 오행으로 본다
③ 그 오행이 양쪽에 걸려 있으면(split) → 기본은 중립(0)
   단 조건부 기신이 걸려 있고 그 기운이 실제로 넘치면 기신으로 발동
④ 과다 판정: 원국 8자 + 해당 층위 간지에서 그 오행이 4개 이상
```

## 3. 채점에 쓰는 법 (`28_scoring.md` §2 ②축)

```
s(조후) ∈ [-1.0, +1.0]
  핵심 용신 천간 도래        → +0.9
  핵심 용신 오행 도래        → +0.6
  보조 희신 천간/오행        → +0.4 / +0.3
  무조건 기신 천간/오행      → -0.8 / -0.6
  조건부 기신 (과다 발동 시)  → -0.5   (미발동이면 0)
  split 오행이면서 천간 불일치 → 0
  아무 데도 안 걸림           → 0
천간과 지지 본기를 각각 채점해 평균한다.
```

⚠️ 조후는 18점 축이다. **격국(①축)을 뒤집지 못한다.** 두 축이 어긋나면 `SKILL.md`의
"格의 성패를 먼저 보고 조후로 세부 보정" 원칙에 따라 격국을 따르고 조후는 보정으로만 쓴다.
