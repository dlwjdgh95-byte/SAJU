## 1. 신살 신뢰도 등급 (Evidence Grade)

신살은 근거의 두께가 서로 크게 다르다. **출력 시 등급을 함께 밝힌다.** 등급 없이 신살을 단정 서술하지 않는다.

| 등급 | 정의 | 서술 강도 |
|---|---|---|
| **A** | 지지·천간의 구조(록왕·생묘·충합)에서 직접 유도되며 격국·강약 판단과 직접 연동 | 판단 근거로 사용 가능 |
| **B** | 유래가 분명하고 임상 관찰이 축적되어 있으나 격국 판단을 뒤집지는 못함 | 보조 근거. "경향" 수준으로 서술 |
| **C** | 조견표는 고정되어 있으나 유래가 약하거나 학파별 표가 갈림 | 참고만. 단독 서술 금지 |
| **D** | 주로 상담 전달용 명칭. 판정 기능 거의 없음 | 명칭 소개 외 사용 금지 |

| 항목 | 등급 | 비고 |
|---|---|---|
| 십이운성(十二運星) | **A** | 천간의 왕쇠 그 자체 |
| 양인(羊刃) | **A** | 일간의 제왕지. 격국론에서 양인격으로 별도 취급 |
| 공망(空亡) | **A~B** | 순중공망은 구조적. 다만 해석 비중에 학파 이견 큼 |
| 12신살 중 역마·지살·장성·화개 | **A~B** | 삼합 구조(생·왕·묘)에서 직접 유도 |
| 12신살 중 겁·재·천·년·월·망·반·육 | **B** | 회전판 위치로 유도되나 해석 폭이 넓음 |
| 원진(怨嗔) | **B** | 충의 옆자리 구조. 임상 관찰 두터움 |
| 귀문관살(鬼門關殺) | **B** | 정신·예민도 지표로 관찰 축적 |
| 격각(隔角) | **B** | 한 칸 건너뜀 = 박자 어긋남. 구조적 유래 명확 |
| 천을귀인(天乙貴人) | **B** | ⚠️ "귀인은 결과가 아니라 통로다" — 있다고 잘되는 것이 아니라 문이 하나 열려 있는 것 |
| 문창·학당귀인 | **B** | 식신 록지 / 장생지에서 유도 |
| 백호대살·괴강 | **B** | 간지 조합 고정. 강도 해석에 이견 |
| 삼재(三災) | **B~C** | 삼합 기준 3년. 대중 인지도 대비 판정력은 낮음 |
| 천라지망(天羅地網) | **C** | 辰巳·戌亥 고정 |
| 금여(金輿) | **C** | 건록+2 자리 |
| 천의성(天醫星) | **C** | 월지 직전 지지 |
| 고신살·과숙살 | **C** | 년지 방합 전후 |
| 천덕·월덕귀인 | **C** | 월지 기준. 표가 학파별로 갈림 |
| 홍염살(紅艶殺) | **C~D** | ⚠️ 근거가 얇다. 조견표도 판본별로 다름 |
| 편야도화·기타 별칭 | **D** | 명칭일 뿐 |

## 2. 십이운성(十二運星) 정본표

일간(천간)이 각 지지에서 갖는 12단계 왕쇠. **개수가 아니라 힘의 상태**를 본다.
"많은데 힘이 없을 수 있고, 하나뿐인데 펄펄 살아 있을 수 있다."

### 2-1. 12단계의 뜻

| 단계 | 상(象) | 실전 질감 |
|---|---|---|
| 장생(長生) | 갓 태어남 | 시작·개화·순수한 의욕. 아직 힘은 얕다 |
| 목욕(沐浴) | 씻고 꾸밈 | 다듬음·치장·변덕. 별칭 패지(敗地) — 방향이 흔들림 |
| 관대(冠帶) | 옷을 갖춰 입음 | 사회 진입·형식 갖춤·의욕 과잉 |
| 건록(建祿) | 록(祿)=봉급 | 자기 몫을 스스로 감당. 자립·본업 |
| 제왕(帝旺) | 왕의 자리 | 최고조. 남의 말을 안 듣는다. 고집·독단 |
| 쇠(衰) | 정점 직후 | 노련함·관리 모드. 확장보다 유지 |
| 병(病) | 뒤처졌는데 못 놓음 | 주도권이 내게 없음. 미련·재정비 |
| 사(死) | 물러남 | **실제 소멸이 아니라 머리가 몸보다 앞섬.** 기획·지식·정신노동에 유리 |
| 묘(墓) | 창고에 넣음 | 저장·침잠·수렴. 화개와 통함 |
| 절(絶) | 끊김 | 단절 후 재출발. 바닥에서의 전환 |
| 태(胎) | 배 속에 듦 | 구상·잉태. 아직 형체 없음 |
| 양(養) | 길러짐 | 준비·의탁·양육 |

### 2-2. 정본표 (음포태 기준)

**세로 = 지지, 가로 = 일간.** 음간(乙丁己辛癸)은 역행시키는 **음포태(陰胞胎)** 기준이다.

| 지지 | 甲 | 乙 | 丙·戊 | 丁·己 | 庚 | 辛 | 壬 | 癸 |
|---|---|---|---|---|---|---|---|---|
| 子 | 목욕 | 병 | 태 | 절 | 사 | 장생 | 제왕 | 건록 |
| 丑 | 관대 | 쇠 | 양 | 묘 | 묘 | 양 | 쇠 | 관대 |
| 寅 | 건록 | 제왕 | 장생 | 사 | 절 | 태 | 병 | 목욕 |
| 卯 | 제왕 | 건록 | 목욕 | 병 | 태 | 절 | 사 | 장생 |
| 辰 | 쇠 | 관대 | 관대 | 쇠 | 양 | 묘 | 묘 | 양 |
| 巳 | 병 | 목욕 | 건록 | 제왕 | 장생 | 사 | 절 | 태 |
| 午 | 사 | 장생 | 제왕 | 건록 | 목욕 | 병 | 태 | 절 |
| 未 | 묘 | 양 | 쇠 | 관대 | 관대 | 쇠 | 양 | 묘 |
| 申 | 절 | 태 | 병 | 목욕 | 건록 | 제왕 | 장생 | 사 |
| 酉 | 태 | 절 | 사 | 장생 | 제왕 | 건록 | 목욕 | 병 |
| 戌 | 양 | 묘 | 묘 | 양 | 쇠 | 관대 | 관대 | 쇠 |
| 亥 | 장생 | 사 | 절 | 태 | 병 | 목욕 | 건록 | 제왕 |

### 2-3. ⚠️ 학파 이견 — 음포태 vs 양포태

| | 음포태(陰胞胎) | 양포태(陽胞胎) |
|---|---|---|
| 음간 취급 | 양간과 반대로 역행 (乙의 장생=午) | 음간도 같은 오행 양간과 동일 (乙=甲으로 봄, 장생=亥) |
| 근거 | 음양은 서로 반대로 운행한다는 원리 | 실전에서 乙이 亥·卯에서 힘을 얻는 관찰 |
| 쓰는 곳 | 십이운성을 독립 지표로 쓰는 계열. 대중 운세 서술 다수 | 통근·강약 판단 계열. **본 저장소의 `ROOT_GRADE`(통근 등급)가 이 방식** |

- **본 저장소 규칙**: 강약·통근 판정은 기존대로 **오행 기준(양포태 계열) `ROOT_GRADE`**를 쓴다.
  십이운성을 **질감·서술 지표**로 쓸 때만 위 §2-2 음포태 표를 쓰고, **어느 기준인지 반드시 명시**한다.
- 두 기준이 갈리는 지점(예: 乙이 亥에서 사(死)인가 생지인가)에서는 **단정하지 않고 두 견해를 병기**한다.
- ⚠️ 이중 계상 금지: 십이운성 판정이 통근·강약축의 재진술이면 `28_scoring.md` §2-1에 따라 감쇠한다.

### 2-4. 인종(引從) — 십신별 운성 읽기

일간뿐 아니라 **십신 10개 각각**을 그 지지에서 인종해 읽으면 해상도가 크게 오른다.

```
절차: 일간 → 십신에 해당하는 천간을 확정 → 그 천간의 §2-2 운성을 대상 지지에서 읽는다
예) 甲 일간, 대상 지지 酉
    비견 甲=태 / 겁재 乙=절 / 식신 丙=사 / 상관 丁=장생 / 편재 戊=사
    정재 己=장생 / 편관 庚=제왕 / 정관 辛=건록 / 편인 壬=목욕 / 정인 癸=병
  → 관성(庚·辛)이 제왕·건록: 직장·명예 쪽 압력과 기회가 동시에 큼
  → 식신은 사, 상관은 장생: 정제된 표현보다 튀어나오는 말이 앞선다
```
서술 시 **"어느 십신이 살아 있고 어느 십신이 눌려 있는가"**로 옮긴다. 운성 명칭 나열로 끝내지 않는다.

## 3. 주요 신살 조견표

### 3-1. 일간 기준

| 신살 | 甲 | 乙 | 丙 | 丁 | 戊 | 己 | 庚 | 辛 | 壬 | 癸 | 등급 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| **양인(羊刃)** | 卯 | — | 午 | — | 午 | — | 酉 | — | 子 | — | A |
| **문창귀인** | 巳 | 午 | 申 | 酉 | 申 | 酉 | 亥 | 子 | 寅 | 卯 | B |
| **학당귀인** | 亥 | 午 | 寅 | 酉 | 寅 | 酉 | 巳 | 子 | 申 | 卯 | B |
| **금여(金輿)** | 辰 | 巳 | 未 | 申 | 未 | 申 | 戌 | 亥 | 丑 | 寅 | C |
| **홍염살(紅艶)** | 午 | 午 | 寅 | 未 | 辰 | 辰 | 戌 | 酉 | 子 | 申 | C~D |

**천을귀인(天乙貴人, B)** — 甲·戊·庚 → 丑·未 / 乙·己 → 子·申 / 丙·丁 → 亥·酉 / 壬·癸 → 巳·卯 / 辛 → 午·寅

```
양인 보충 (A):
- 일간의 제왕지. 극단적 강함 → 과격·사고·수술·칼의 상(象).
- 음간 양인은 없다는 견해가 주류. 있다고 보는 학파는 乙→辰, 丁己→未, 辛→戌, 癸→丑(묘고)로 잡는다. 병기만 하고 단정하지 않는다.
- 실전 발동 조건: 양인이 충당하거나(양인충), 관살과 만나거나(양인합살), 운에서 양인이 겹칠 때(중양인).
- 신살 중 격국 판단에 개입할 수 있는 몇 안 되는 항목.

천을귀인 보충 (B):
- ⚠️ "귀인이 있으면 잘 풀린다"는 서술 금지. 귀인은 **결과가 아니라 통로**다 — 문이 하나 열려 있다는 뜻이지
  누가 들어와 준다는 뜻이 아니다. 격국이 나쁘면 유명무실하다.

문창 vs 학당:
- 문창 = 일간의 식신이 록을 얻는 자리 → 표현·문서·시험
- 학당 = 일간의 장생지 → 배움·수학(受學)
- 丁·己는 둘이 酉에서 겹친다. 겹치는 자리는 공부·강학(講學) 쪽으로 특히 유리하다고 본다.
```

### 3-2. 년지 기준

**삼재(三災, B~C)** — 년지 삼합국별로 3년간.

| 년지가 속한 국 | 삼재 해당 년지 (들·눌·날) |
|---|---|
| 申子辰 | 寅 → 卯 → 辰 |
| 亥卯未 | 巳 → 午 → 未 |
| 寅午戌 | 申 → 酉 → 戌 |
| 巳酉丑 | 亥 → 子 → 丑 |

**고신살(孤神)·과숙살(寡宿) (C)** — 년지 방합 기준. 고신=방합 다음 계절 첫 글자, 과숙=앞 계절 끝 글자.

| 년지 | 고신 | 과숙 |
|---|---|---|
| 亥·子·丑 | 寅 | 戌 |
| 寅·卯·辰 | 巳 | 丑 |
| 巳·午·未 | 申 | 辰 |
| 申·酉·戌 | 亥 | 未 |

12신살(겁·재·천·지·년·월·망·장·반·역·육·화)의 년지 기준 배치는 → `29_sibisinsal.md` §2

### 3-3. 일주(간지 조합) 기준

```
백호대살(白虎大煞, B) — 7개 간지
  甲辰 · 乙未 · 丙戌 · 丁丑 · 戊辰 · 壬戌 · 癸丑
  상(象): 피를 보는 격렬함. 사고·수술·급변. 다만 현대에는 "강한 추진력"으로 읽는 견해가 넓다.
  일주에 있을 때 비중이 가장 크고, 다른 기둥은 약화해서 본다.

괴강(魁罡, B) — 庚辰 · 庚戌 · 壬辰 · 壬戌 (+ 戊辰 · 戊戌을 포함하는 견해)
  상(象): 극단적 리더십·결벽·흑백논리. 대귀(大貴) 아니면 대패(大敗)라는 고전 서술.
  ⚠️ 여성 명조에 대한 고전의 부정 서술은 시대적 산물이므로 그대로 옮기지 않는다.

공망(空亡, A~B) — 일주가 속한 순(旬)에서 빠진 2지지
  甲子순 → 戌亥 / 甲戌순 → 申酉 / 甲申순 → 午未
  甲午순 → 辰巳 / 甲辰순 → 寅卯 / 甲寅순 → 子丑
  상(象): 뜻은 있으나 실체가 비어 있음. 그 자리의 십신이 "생각만큼 잡히지 않음".
  ⚠️ 학파 이견 큼: 운에서 채워지면 정상 작동한다는 견해 vs 평생 비어 있다는 견해. 병기한다.
  공망이 충·합을 만나면 해공(解空)된다는 규칙을 쓰는 학파도 있다.
```

### 3-4. 월지 기준

```
천의성(天醫星, C) — 월지 바로 앞 지지 (寅월→丑, 卯월→寅, … 子월→亥, 丑월→子)
  상(象): 남을 살리는 자리. 의료·상담·돌봄 직군과의 친연성.

천덕·월덕귀인(C) — 월지 기준. 표가 학파별로 갈리므로 조견이 필요하면 근거 판본을 밝히고 인용한다.
  상(象): 재앙을 덜어내는 보호. 실전 비중 낮음.
```

## 4. 신살 출력 규범

```
① 신살명 + 등급 + 기준(일간/년지/일지/월지/일주) + 자리 + 근거를 한 줄에 묶어 표기한다.
   예) "역마살(A~B · 년지 子 기준 · 월지 寅) — 申子辰국의 생지 申을 충하는 자리"

② C·D 등급 신살은 단독 문장으로 쓰지 않는다. A·B 판단에 곁들이는 부사구로만 쓴다.

③ 길신은 "통로", 흉살은 "장면"으로 옮긴다. 결과 선언에 쓰지 않는다.

④ 신살이 격국·용신 판단과 어긋나면 격국을 따르고, 신살은 표면 사건으로 강등해 병기한다.
```
