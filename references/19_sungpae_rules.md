# 자평진전(子平眞詮) — 성격·패격·구격 판단 규칙

> 이 문서는 8개 격국에 공통 적용되는 성패 판단 원칙을 정리한 것이다.
> 각 격국 문서와 함께 읽으면 실전 사주 판단에 직접 활용할 수 있다.

---

## 1. 성격(成格) 판단의 3가지 기준

### 기준 ①: 월령(月令) 득기(得氣)

격국의 핵심 오행(정관·칠살·인성·재성·식신·상관 등)이 월령에서 힘을 얻어야 한다.

```
판단 방법:
1. 월지 장간을 확인
2. 그 장간이 천간에 투출했는지 확인
3. 투출된 오행이 지지에 뿌리(통근)를 두고 있는지 확인
→ 세 조건이 갖춰질수록 격이 높음
```

### 기준 ②: 용신(用神)의 건재

각 格에서 요구하는 용신이 힘 있게 존재해야 한다.

| 격국 | 핵심 용신 |
|---|---|
| 정관격 | 재성(재생관) 또는 인성(관인상생) |
| 칠살격 | 식신·상관(제살). 인성(화살)은 인이 유정하거나 식신 없이 인으로 감당할 때(「有七煞用印者，印能护煞，本非所宜，而印有情，便为贵格」) |
| 정인격 | 관성(관인상생 — 겨울 木은 예외: 「冬木逢水，虽透官星，亦难必贵」). 인다신강이면 재성, 신강인왕이면 식상(§10) |
| 편인격 | 관성(관인상생). 인다신강이면 재성, 신강인왕이면 식상(§10) |
| 정재격 | 식상(식상생재) 또는 관성(재생관) |
| 편재격 | 식상(식상생재) 또는 관성(재생관) |
| 식신격 | 재성(식신생재) 또는 칠살(식신제살) |
| 상관격 | 재성(상관생재) 또는 인성(상관패인) |

### 기준 ③: 기신(忌神)의 부재 또는 제어

각 格을 파괴하는 기신이 없거나, 있더라도 완전히 제어되어야 한다.

```
제어의 조건:
① 기신이 천간에 없는 경우 (지지에만 있으면 영향 감소)
② 기신이 다른 오행에 의해 극(剋)당하는 경우
③ 기신이 합거(合去)되어 기능을 잃은 경우
④ 기신의 세력이 용신보다 현저히 약한 경우
```

## 2. 格을 파(破)하는 주요 조합

### 공통 파격 조합

**① 관살혼잡(官殺混雜)**

정관과 칠살이 천간에 함께 나타나는 상황.
- 영향 격: 정관격, 칠살격 모두
- 해결: 합살유관(칠살이 합거) 또는 합관유살(정관이 합거)

**② 재다신약(財多身弱)**

재성이 너무 많고 일간이 약한 상황.
- 영향 격: 정재격, 편재격
- 일간의 힘이 재를 감당하지 못해 격이 손상됨

**③ 인성피재(印星被財)**

인성이 재성에 의해 극파되는 상황 (재파인).
- 영향 격: 정인격, 편인격, 상관패인 구조
- 해결: 비겁이 재성 제어

**④ 식신피인극(食神被印剋) — 탈식(夺食)**

인이 식신을 극하는 탈식(夺食). 흔히 편인의 일로 보아 효신도식(梟神盜食)이라 부르지만 정인도 같다(「食神虽逢正印，亦谓夺食」). 다만 여름 木은 예외다 — 같은 문장이 「而夏木火盛，轻用之亦秀而贵」로 이어진다(钱参政 〔丙午 癸巳 甲子 丙寅〕: 「夏火太炎而木焦，透印不碍」, 논식신).
- 영향 격: 식신격(월령 식신). 인격(월령 인)에 식신이 투출한 것은 설수이지 탈식이 아니다 — 「见偏印透食，不以为泄身之秀，而以为枭神夺食…此皆由不知月令而妄论之故也」(논용신)
- 해결: 재성이 인 제어(「更有印来夺食，透财以解」), 또는 칠살로 격을 바꿈(「食逢枭而就煞以成格」)

### 格별 핵심 파격 조합

| 격국 | 핵심 파격 조합 | 파격 원인 |
|---|---|---|
| 정관격 | 상관견관 | 상관이 정관 극파 |
| 정관격 | 겁재(정관용재일 때만) | 원문의 정관격 败는 「官逢伤克刑冲」뿐이다. 재를 써서 관을 생할 때 겁재가 그 재를 치는 정도이고, 관살혼잡에서는 오히려 겁재로 살을 합하기도 한다(「其命中用劫合煞，则财运可行」, 논정관취운) |
| 정관격 | 관살혼잡 | 칠살이 정관의 순수성 훼손 |
| 칠살격 | 재성생살 | 재가 살을 생해 살이 더 강해짐 |
| 칠살격 | 살강식약 | 살이 강하고 식신이 약해 제어 불가 |
| 정인격 | 재파인(財破印) | 「印轻逢财」 — 인이 가볍고 재가 무거울 때다. 인다신강이면 재가 오히려 용신이다(「印多逢财而财透根轻，印格成也」) |
| 정인격 | 신강인중에 칠살 | 「身强印重而透煞，印格败也」 — 살이 인을, 인이 일간을 생해 지나침. 식상이 함께 있어 살을 제어하면 귀격이다(「有用煞而兼带伤食者，则用煞而有制，生身而有泄，不论身旺印重，皆为贵格」) |
| 편인격 | 재파인·신강인중에 칠살 | 정인격과 같다(「财与印不分偏正」) — 예외(인다용재, 살에 식상 겸대)도 같다. 식신 투출은 설수이지 효신도식이 아니다(「偏印透食…泄身之秀」) |
| 정재격 | 겁재탈재 | 「财轻比重」 — 재가 가볍고 비겁이 무거울 때. 재용식생에 비겁 하나는 유정하다(「略带一位比劫，益觉有情」) |
| 편재격 | 겁재탈재 | 정재격과 같다 |
| 정재격 | 재투칠살 | 「财透七煞，财格败也」 — 재가 살을 생함. 합살존재·제살생재면 귀격이다(「有财带七煞者，或合煞存财，或制煞生财，皆贵格也」, 毛状元·李御史) |
| 편재격 | 재투칠살 | 정재격과 같다 |
| 식신격 | 탈식(夺食 — 편인이면 효신도식) | 인(정·편)이 식신 극파 — 여름 木은 예외(「夏木火盛，轻用之亦秀而贵」) |
| 식신격 | 생재노살(生財露煞) | 「食神逢枭，或生财露煞，食神格败也」 — 재가 살을 생함 |
| 식신격 | 살강식약 | 살이 강해 식신의 제살 기능 무력화 |
| 상관격 | 상관견관(금수 제외) | 「伤官非金水而见官」 — 금수상관은 관을 반긴다(「金水独宜」) |
| 상관격 | 생재대살 | 「或生财而带煞」 — 재가 살을 생함 |
| 상관격 | 패인에 상관이 약하고 신왕 | 「或佩印而伤轻身旺」 — 패인은 상관이 왕하고 신이 조금 약해야 한다(「反要伤官旺，身稍弱」) |
| 상관격 | 패인에 재가 인을 침 | 「佩印而印又遭伤」(带忌). 다만 재·인을 겸용해 천간이 서로 막히지 않으면 귀격이다(「有伤官兼用财印者…只要干头两清而不相碍…调停中和，遂为贵格」, 都统制·一丞相) |

## 3. 格을 구(救)하는 주요 조합

### 공통 구격 원리

**원리 ①: 기신을 극(剋)하는 오행 존재**

기신을 직접 극하는 오행이 사주에 있으면 기신의 기능이 약화된다.

```
기신 → 기신을 극하는 오행(구신) → 구격
```

**원리 ②: 기신을 합거(合去)하는 천간합**

기신이 다른 오행과 천간합을 이루어 본래 기능을 잃을 때 구격이 된다.

```
예: 상관(기신) + 다른 오행 → 합거 → 상관의 정관 극 기능 약화
```

**원리 ③: 용신을 생(生)하는 오행 존재**

용신이 약할 때 용신을 생하는 오행(희신)이 있으면 용신이 강화된다.

### 格별 핵심 구격 조합

| 격국 | 패격 원인 | 구격 방법 |
|---|---|---|
| 정관격(상관견관) | 상관이 정관 극 | 인성이 상관 극제(「官逢伤而透印以解之」), 또는 재가 상관을 설해 관을 생함(「透财而地位配置合宜，则伤官生财来生官，反可以解」) |
| 정관격(용재에 겁재) | 겁재가 재성을 침 | 관이 겁재를 누른다(재격 구응의 「生官以制之」). 식상으로 화하면 관을 치니 정관격에서는 쓰기 어렵다 |
| 정관격(관살혼잡) | 칠살 혼재 | 합살유관(칠살 합거) |
| 칠살격(재성생살) | 재가 살 생함 | 식신이 살을 제어하고, 재는 식신을 막는 인을 제거(「财以去印存食」, 周丞相). 신중살경이면 재가 오히려 살을 도와 격을 맑힌다(「借财以清格」, 刘运使) |
| 정인격(재파인) | 재가 인 극파 | 비겁이 재성 극제, 재를 합해 인을 지킴(「印逢财而劫财以解之，或合财而存印」) |
| 편인격(재파인) | 재가 인 극파 | 비겁이 재성 극제, 재를 합해 인을 지킴(「印逢财而劫财以解之，或合财而存印」) |
| 재격(겁재탈재) | 겁재가 재 탈취 | 식상이 겁재를 화한다(「财逢劫而透食以化之」, 「财逢比劫，伤官可解，伤能成格也」 — 汪学士), 또는 관이 겁재를 누른다(「生官以制之」) |
| 재격(재투칠살) | 재가 살을 생함 | 식신이 살을 제어하거나 살을 합한다(「逢煞而食神制煞以生财，或存财而合煞」 — 李御史·毛状元) |
| 식신격(탈식) | 인(정·편)이 식신 극 | 재성이 인 극제(「透财以解」), 칠살로 격을 바꿈(「食逢枭而就煞以成格」), 생재로 식신 보호(「或生财以护食」) |
| 상관격(상관견관) | 상관이 정관 극 | 인성이 상관 극제(상관패인), 또는 재가 상관을 설해 관을 생함(「透财…反可以解」) |
| 상관격(패인에 재) | 재가 인 극파 | 비겁이 재성 극제. 재·인이 천간에서 서로 막히지 않으면 겸용한다(「只要干头两清而不相碍」) |

## 4. 패중취귀(敗中取貴) — 패격이 귀해지는 원리

> 「败中有成，全凭救应」 — 패격이라도 구응이 있으면 이룬다(논용신성패구응)

자평진전의 가장 중요한 통찰 중 하나다. 사주가 표면적으로 패격처럼 보여도, 구신(救神)이 기신을 완전히 제어하면 오히려 더 복잡하고 강력한 명이 된다.

```
패중취귀의 대표 구조:

[정관격 패중취귀]
정관격 → 상관이 정관 극(패격 발생) → 인성이 상관 제어(구격)
→ 관·상관·인성의 삼중 구조로 오히려 복잡하고 귀한 명

[칠살격 패중취귀]
칠살격 → 재성이 살 생(패격 발생) → 식신이 살을 제어하고, 재성은 식신을 막는 인을 제거(「财以去印存食」). 신중살경이면 재로 살을 돕는 것이 오히려 맞다(「借财以清格」)
→ 살·재·식신의 역동적 구조로 귀한 명
```

**패중취귀의 조건**:
1. 패격의 원인(기신)이 명확할 것
2. 구신이 기신을 완전히 제어할 것 (부분 제어는 불충분)
3. 구신 자체가 충분한 힘(통근)을 가질 것

## 5. 격국의 고저(高低) 판단 종합 기준

### 높은 격국 (귀명)

1. 격국의 핵심 오행이 월령 득기하고 천간 투출
2. 용신이 힘이 있고 지지에 뿌리가 있음
3. 기신이 전혀 없거나 완전히 제어됨
4. 천간이 맑고 오행이 단순하며 혼탁하지 않음
5. 용신·희신·기신의 관계가 명확함

### 낮은 격국

1. 격국 오행이 월령 득기했으나 천간 투출 없음
2. 용신이 있으나 뿌리가 약함
3. 기신이 있으나 부분적으로만 제어됨
4. 천간이 혼탁하여 오행이 복잡하게 얽힘

### 극히 낮은 격국 (천한 명)

1. 기신이 있고 구신도 없어 패격이 방치됨
2. 용신이 없거나 완전히 파괴됨
3. 관살혼잡·재파인·효신도식 등이 해결되지 않음

## 6. 천간 투출과 지지 통근의 중요성

### 투출(透出)이란

월지 장간이 천간에 드러나는 것. 투출이 있으면 격국의 힘이 강하고 명확해진다.

### 통근(通根)이란

천간에 있는 오행이 지지에 같은 오행(또는 같은 오행을 포함하는 지지)이 있어 힘을 얻는 것.

```
예: 천간의 甲木이 지지에 寅·卯·亥(甲木의 통근지)가 있으면 통근됨
```

통근 없는 천간은 뿌리 없는 나무 — 겉으로 있어 보이지만 실력이 없다.

### 투출+통근의 이상적 조합

격국에서 가장 강력한 구조:
1. 격국 오행이 월지에서 득기(得氣)
2. 천간에 투출
3. 천간의 해당 오행이 다른 지지에도 통근
→ 이 세 조건이 모두 갖춰지면 격이 강고(强固)하다

## 7. 혼탁(混濁)과 맑음(淸純) — 격국의 질적 차이

자평진전이 강조하는 중요 개념이다.

### 맑은(淸純) 사주

오행의 관계가 단순하고 명확하다. 格의 용신·기신이 뚜렷하며, 불필요한 오행이 없다.

### 혼탁(混濁)한 사주

여러 오행이 복잡하게 얽혀 格의 방향이 불분명하다. 용신과 기신이 서로 뒤섞여 格의 순수성이 손상된다.

```
혼탁의 대표 사례:
- 관살혼잡: 정관과 칠살이 함께 있어 관의 성격이 불분명
- 재인상극(財印相剋): 재성과 인성이 서로 극하여 용신이 손상 — 「财印相克，本不并用」(논상관), 「甲生辰月，戊壬并透，印与财相克，亦两不相谋也」(논용신순잡). 천간에서 서로 막히지 않으면 겸용한다(「只要干头两清而不相碍」)
- 식상혼잡: 식신과 상관이 함께 있어 설기의 방향이 분산
```

## 8. 학파 간 주요 이견 정리

### 이견 ①: 격국론 vs 억부론

**자평진전(격국론)**: 용신은 격국에서 취한다. 월령이 제강이다.

**적천수·현대 억부론**: 일간의 강약을 먼저 판단하고 용신을 취한다. 신강이면 극설, 신약이면 생조.

**정리**: 자평진전은 억부를 완전히 부정하지 않지만, 격국을 먼저 판단하고 그 안에서 신강·신약을 고려한다. 억부론은 格보다 일간 강약을 우선시한다.

### 이견 ②: 격국론 vs 조후론

**자평진전(격국론)**: 계절의 기후는 참고하지만, 격국 성패가 더 중요하다.

**궁통보감(조후론)**: 일간이 태어난 월의 기후와 필요한 오행을 용신으로 취한다.

**정리**: 현대 명리학은 두 이론을 병용하는 경향이 있다. 격국으로 기본 구조를 보고, 조후로 세부 보정을 한다.

### 이견 ③: 격국의 변화 — 종격(從格) 문제

**자평진전**: 팔격 중심이며 종격에 대한 논의가 상대적으로 적다.

**적천수 및 일부 학파**: 일간이 극도로 약하거나 강할 때 종격(從財格·從殺格·從強格 등)으로 판단한다.

**정리**: 종격의 성립 조건과 범위에 대한 학파 간 이견이 매우 크다.

### 이견 ④: 용신의 수

**자평진전**: 格은 월령 하나에서 세우지만, 그것을 돕는 글자는 둘을 함께 써도 된다. 서로 도우면 순수하고(「何谓纯？互用而两相得者是也」), 서로 다투면 잡하다(「何谓杂？互用而两不相谋者是也」, 논용신순잡). 잡기월은 「一透则一用，兼透则兼用」(논잡기여하취용)이다. 혼탁은 쓰는 글자가 여럿이어서가 아니라 서로 해칠 때다.

**현대 일부 학파**: 주용신(主用神)·보조용신의 개념으로 복수 용신을 인정한다 — 자평진전의 겸용과 가깝다.

## 9. 실전 판단 프로세스

자평진전 격국론을 실전에 적용할 때의 순서:

```
Step 1: 월령 확인
        → 월지와 그 장간(여기→중기→본기)을 확인

Step 2: 특수 월령을 먼저 본다 (errata #20)
        → 辰戌丑未월 → 잡기: 투출 > 고(庫)의 오행과 같은 오행 투간 > 회지 > 본기 (35번)
        → 월지 = 일간 록지 → 건록 / 양간·월지 양인 → 양인 / 음간·월지 본기 겁재 → 월겁 (34번)
          록겁은 용신이 아니므로 투간·회지한 재·관·살·식상으로 용신을 따로 취한다

Step 3: 그 외 월령은 본기로 格을 세운다
        → 본기가 일간과 어떤 관계인지로 정관·칠살·정인·편인·정재·편재·식신·상관 중 하나를 정한다
        → 본기가 투출하면 더 맑다. 투출하지 않아도 본기가 1순위다
        → 본기가 불투하고 중기·여기가 투출하면 '변화 후보' — 원문은 본기가 불투하고 중기가 투출하면 중기가 작주한다고 한다(「不透甲而透丙」, 논용신변화)
        → 본기가 불투한 채 월지가 낀 삼합이 다 모이면 국의 오행도 변화 후보(「支全卯未，则化为印」)
        → 본기도 투출했으면 변하지 않는다(「丙生寅月，午戌会劫，而又或透甲，或透壬，则仍为印而格不破」의 「或透甲」). 국의 정·편은 투간으로만 가린다
        → 다른 투간이 본래 격을 지켜도 변하지 않는다(「或透壬」, 「丙生申月，逢壬化煞，而又透戊…仍为财格」) — 스크립트가 판정하지 않으니 사람이 본다
        → 24번 71命이 본기 1순위로 모두 맞으므로 본기를 1순위로 둔다
        → `saju_calc.py`의 `격 후보`가 이 순서로 낸다

Step 4: 용신 결정
        → 해당 格에서 요구하는 용신이 사주에 있는지 확인
        → 용신의 강약(통근 여부) 확인

Step 5: 기신 확인
        → 格을 파괴하는 기신이 있는지 확인

Step 6: 성격·패격·구격 판단
        → 기신이 없거나 제어됨 → 성격
        → 기신이 있고 제어 안 됨 → 패격
        → 기신이 있지만 구신이 제어 → 구격(패중취귀 가능)

Step 7: 격국의 고저 판단
        → 용신의 강약 + 기신의 유무로 높고 낮음 결정
```

## 10. 格별 용신·기신 빠른 참조 (원국 성패 판정용)

| 상관용살인 | 인·식상 | 관·재 | 「伤官而用煞印，印运最利，伤食亦亨，杂官非吉，逢财即危」 |
| 상관용관(금수) | 재·인 | 식상 | 「伤官用官，运喜财印，不利食伤」 |

건록·월겁·양인의 취운은 34번 §2-2·§3-6, 잡격은 원문 논잡격 각 항(「运喜…」)을 따른다.

**⚠️ 재격·인격에서 식상의 역할 — 格이 무엇을 쓰는지로 갈린다**:
- 재격이 **관을 쓰면**(재왕생관) 상관은 관을 깨는 기신이다 — 「财旺生官者，身强而不透伤官，不混七煞，贵格也」(24번 论财-01).
- 재격이 **관 없이 식상을 쓰면**(재용식생) 식상이 용신이다. 다만 신강해야 한다 — 신약한데 관이 드러나면 「透官身弱，则格坏矣」(24번 论财-02).
- 그래서 재격의 식상 대운은 용관이면 흉, 재용식생이면 길이다. 신약하면 식상이 일간을 더 설기하므로 길로 단정하지 않는다.
- 인격(정인·편인)도 **신강인왕**이면 식상 설기가 용신이 된다 — 「有印而用伤食者，身强印旺，恐其太过，泄身以为秀气」(24번 论印绶-04 李状元). 효신도식(夺食)은 월령 식신을 인이 극할 때의 말이다 — 정인도 같고(「食神虽逢正印，亦谓夺食」, 논용신배기후득실), 여름 木은 예외다(「而夏木火盛，轻用之亦秀而贵」). 인격에 식신이 투출한 것은 설수다(「见偏印透食，不以为泄身之秀，而以为枭神夺食…此皆由不知月令而妄论之故也」, 논용신).

**⚠️ 구신(救神) 합거 — 반드시 확인**:
- 구신은 기신을 제어하여 格을 살리는 오행이다.
- 대운·세운이 구신을 합거하면 → 기신이 되살아나 패격 → 흉
- 예) 정재격에서 겁재(기신)를 관성(구신)이 제어 중일 때, 대운에서 관성이 합거되면 → 겁재탈재 재발 → 흉

**⚠️ 조후 용신 ≠ 격국 용신일 때**:
- 격국 용신과 조후 용신이 다를 수 있다.
- 조후 용신이 격국의 기신일 경우: 格의 성패를 먼저 보고 조후는 보조로 참고한다.
- 조후 용신이 格에도 유익할 경우(겸용): 해당 오행의 가치가 더욱 높아진다.
- 어느 대운이든, 격국과 조후 **양쪽에서** 그 오행의 역할을 반드시 검토한다.
