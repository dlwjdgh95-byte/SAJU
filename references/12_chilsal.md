# 자평진전(子平眞詮) — 칠살격(七殺格)

> 자평진전 격국론 시리즈 2편. 칠살격은 정관격과 대비되는 살(殺)의 논리다.
> 원칙은 제어다 — 「七煞喜食神以制伏，忌财印以资扶」(논용신). 다만 원문은 식신 없이 인이나 양인으로 살을 감당하는 길도 든다(「有煞无食制而用印当者」, 논편관 / 「煞无食制而用刃当煞」, 논편관취운).

---

## 1. 정의와 본질

칠살격(七殺格)은 **월지 본기가 편관**이면 성립한다 — 투출하면 더 맑고, 투출하지 않아도 1순위다. 본기가 불투하고 중기·여기의 편관이 투출했거나, 본기가 불투한 채 월지가 낀 삼합이 다 모여 국이 관살 무리가 되면 이 격으로 변할 수 있는 **변화 후보**다 — 원문은 본기가 불투하고 중기가 투출하면 중기가 작주한다고 하고(「不透甲而透丙」), 회국도 격을 바꾼다고 한다(「支全卯未，则化为印」, 논용신변화). 원전은 반합도 국으로 본다(「甲不透干而会午会戌，则化为劫」, 赵知府 徐注 「寅午化印为劫」) — 스크립트는 삼합이 다 모일 때만 변화 후보를 내므로 반합은 직접 따진다. 본기도 투출했으면 변하지 않는다(「丙生寅月，午戌会劫，而又或透甲，或透壬，则仍为印而格不破」의 「或透甲」 — 「或透壬」은 다른 투간이 격을 지키는 경우다, SKILL 4-1 ⑤). 국의 정·편은 투간으로만 가리고, 투간이 없거나 정·편이 함께 투간하면 스크립트는 '관살격(회국 변화 후보)'처럼 무리로 적는다 — 원문의 「化为印」, 徐注의 「伤化为财」「劫化为食伤」처럼 원전도 무리로 부른다. 辰戌丑未월은 잡기 절차(`35_japgi.md`), 건록·양인·월겁 월령은 `34_geonrok_yangin.md`를 먼저 탄다 (SKILL.md 4-1, errata #20).
편관(偏官)이란 일간을 음양이 같게 극(剋)하는 오행으로, 칠살(七殺)이라고도 부른다.

| 일간 | 칠살(편관) |
|---|---|
| 甲(양목) | 庚(양금) |
| 乙(음목) | 辛(음금) |
| 丙(양화) | 壬(양수) |
| 丁(음화) | 癸(음수) |
| 戊(양토) | 甲(양목) |
| 己(음토) | 乙(음목) |
| 庚(양금) | 丙(양화) |
| 辛(음금) | 丁(음화) |
| 壬(양수) | 戊(양토) |
| 癸(음수) | 己(음토) |

**칠살의 본질**: 정관이 법도 안에서 일간을 다스린다면, 칠살은 압박과 강제력으로 일간을 극한다. 제어(制)되지 않으면 흉하고, 제어되면 강력한 권력과 리더십으로 전환된다.

> 원문: 「身强七煞逢制，煞格成也」「七煞逢财无制，七煞格败也」(논용신성패) — 신강하고 살이 제어되면 성격, 재가 살을 돕는데 제어가 없으면 패격이다. 「盖控制得宜，煞为我用」(논편관).

---

## 2. 성립 조건

월지 본기가 편관이면 칠살격이 성립한다. 중기·여기의 편관 투출은 변화 후보이고, 본기와 함께 볼 때는 본기가 먼저다. (옛 서술 "월지 장간 중 투출하면 성립"은 투출 우선 규칙이라 폐기 — errata #20)

**핵심 원칙 — 칠살의 순수성**

> 「有煞而杂官者，或去官，或去煞，取清则贵」 — 살에 관이 섞이면 하나를 없애 맑혀야 귀하다(논편관). 운에서도 「七煞既纯，杂官不利」(논편관취운).

정관이 섞이면 혼잡해진다. 혼잡은 거관유살·거살유관으로 맑힌다.

## 3. 용신·희신·기신

### 용신

**① 식신(食神) — 식신제살(食神制殺)**

식신이 칠살을 극(剋)하여 살의 폭력적 기운을 제어한다. 이것이 칠살격에서 가장 이상적인 용신 구조다.

```
구조: 식신(食) →극→ 칠살(殺) →극→ 일간(我)
      식신이 살을 막아 일간을 보호
```

**② 인성(印星) — 인성화살(印星化殺), 차선**

원문은 인으로 살을 화하는 것을 원칙상 마땅치 않다고 본다 — 「有七煞用印者，印能护煞，本非所宜，而印有情，便为贵格」(何参政), 살이 무겁고 신이 가벼워 식신을 감당하지 못할 때 인으로 돌린다(「亦有煞重身轻，用食则身不能当，不若转而就印…格亦许贵，但不大耳」, 논편관). 인성이 칠살을 설기(洩氣)하여 살의 기운을 부드럽게 한다. 살이 인성을 생하고(殺生印), 인성이 일간을 생하는(印生我) 구조로 살의 에너지를 유용하게 전환한다.

```
구조: 칠살(殺) →생→ 인성(印) →생→ 일간(我)
      살의 에너지가 인성을 거쳐 일간을 돕는 형상
```

### 기신

**① 재성(財星) — 재성생살(財星生殺)**

> 「七煞逢财无制，七煞格败也」 — 재가 살을 돕는데 제어가 없으면 패격이다(논용신성패구응).

재성이 칠살을 생(財生殺)하면 이미 강한 살이 더욱 맹렬해진다. 칠살격에서 재성은 **원칙상** 기신이다(「财以党煞，本非所喜」). 예외 둘 — 식신이 인에 막혔을 때 재가 인을 제거하는 경우(「财以去印存食，便为贵格」, 周丞相)와 신중살경에서 재로 살을 돕는 경우다. 뒤의 것은 원문이 직접 든다 — 「又有身重煞轻，煞又化印，用神不清，而借财以清格，亦为贵格」(刘运使 〔甲申 乙亥 丙戌 庚寅〕), 운에서도 「其以财而助煞不及者…财未足，则喜财旺而露煞」. 徐注도 「身强煞弱，用财滋煞，非不能也」라 한다. §9 이견 ①.

**② 상관(傷官) — 기신이 아니라 제살의 한 길**

상관도 살을 제어할 수 있다. 다만 칠살격 장(논편관)은 제살로 식신만 들고, 상관이 살을 차는 문장은 상관격 쪽이다 — 월령 상관에 살: 「伤官带煞，随时可用，而用之冬金，其秀百倍」(논용신배기후득실), 상관용살인(인도 함께 씀): 「煞因伤而有制，两得其宜」(夏阁老, 논상관). 그래서 칠살격의 상관제살은 식신제살에 견주어 읽되, 원문이 불안정하다고 한 적은 없다. 다만 정관이 함께 있으면 상관이 정관을 치므로 혼잡을 먼저 정리한다.

**③ 인성과 식신의 충돌 — 인수화식(印綬化食)**

식신이 살을 제하는데 인이 오면 인이 식신을 극(印克食)하여 제살을 방해한다 — 「七煞逢食制而又逢印」(带忌, 논용신성패구응), 「畏印绶之夺食」(논편관취운). 재가 인을 없애면 풀린다(「而逢财以去印存食」).

## 4. 성격(成格)

### 유형 ① 식신제살(食神制殺)

```
구조: 식신이 칠살을 제어

예시: 甲木 일간, 申월(庚金 칠살 투출), 천간에 丙火 식신
      丙火가 庚金을 극(火克金) → 살이 제어됨 → 성격
```

이것이 칠살격의 가장 이상적 형태다. "칠살이 있으면 식신이 있어야 귀하다"는 원칙이 여기서 나온다.

### 유형 ② 인성화살(印星化殺)

```
구조: 살이 인성을 생하고 인성이 일간을 생

예시: 甲木 일간, 申월(庚金 칠살), 천간에 壬水 편인
      庚金이 壬水를 생(金生水) → 壬水가 甲木을 생(水生木)
      → 살의 에너지가 인성을 통해 일간을 도움
```

### 유형 ③ 양인당살(用刃當煞) — 식신이 없을 때

원문의 칠살격 성격은 제어가 조건이다 — 「身强七煞逢制，煞格成也」(논용신성패구응), 徐注 「若身强煞弱，或煞强身弱，皆不能以制伏为用，必身煞两停者，方许成格」. 식신이 없으면 인으로 감당하거나(유형 ②, 「有煞无食制而用印当者」, 赵员外) 양인으로 감당한다(「煞无食制而用刃当煞」, 논편관취운 — 徐注 「煞无食制，全恃身强，方能敌煞，身强必是用刃也」). 제어 없이 신강만으로 살을 쓴다는 '칠살독살'은 원문에 없는 후대 말이다.

## 5. 패격(敗格)

### 유형 ① 재성생살(財星生殺)

```
예시: 甲木 일간, 申월(庚金 칠살), 천간에 戊土 편재
      戊土가 庚金을 생(土生金) → 칠살이 더욱 강해짐 → 패격
```

### 유형 ② 제살과다(制殺過多)

제어가 오히려 지나쳐 살이 완전히 무력화될 때도 문제가 된다. 살이 완전히 없어지면 칠살격이 성립되지 않는다.

```
예시: 申월(庚金 칠살), 丙火 식신 여럿 → 살이 완전 제압
      → 칠살격의 살 자체가 없어져 격 소멸
```

다만 원문은 이 말을 절대화하지 않는다 — 「至书有制煞不可太过之说，虽亦有理，然运行财印，亦能发福，不可执一也」(논편관). 제살이 지나쳐도 재·인 운이 살을 살리면 발복한다.

### 유형 ③ 식신피합(食神被合)

제살 역할의 식신이 다른 오행과 합거(合去)되어 제살 기능을 잃을 때 패격이 된다.

---

## 6. 구격(救格)

### 유형 ① 재생살의 구응 — 식신제살·양인해액

재성이 살을 생하여 패격이 될 때, 식신이 살을 직접 제하거나(「财先食后，财生煞而食以制之」, 논편관) 양인이 재를 막는다(「财逢七煞，刃可解厄，刃能成格也」, 논사흉신능성격). 식상은 재를 생하므로 재를 제어하지 못한다.

### 유형 ② 합재유식(合財留食)

기신 재성이 합거되어 식신의 제살 기능이 살아날 때 구격이 된다.

### 유형 ③ 거인유식(去印留食)

인성이 식신을 극하여 패격이 될 때, 재성이 인성을 제어(財克印)하여 식신의 제살 기능을 회복시킨다.

---

## 7. 칠살격의 특수 구조

**살인상생(殺印相生)**: 칠살이 인성을 생하고 인성이 일간을 생하는 구조. 원전 실례(茅状元·马参政, 14번 §4)는 문관이다 — 무관·문관을 구조만으로 단정하지 않는다.

**식신제살(食神制殺)의 귀격**: 원칙은 재도 인도 드러나지 않아야 식신의 제살이 온전하다(「煞用食制，不要露财透印」 — 재는 식신을 돌려 살을 생하고, 인은 식신을 쳐 살을 지킨다). 다만 재가 앞에 있고 식신이 뒤에서 제하거나, 식신이 지나쳐 인이 덜어내면 오히려 대귀다(「然而财先食后，财生煞而食以制之，或印先食后，食太旺而印制，则格成大贵」, 논편관).

**양인합살(羊刃合殺)**: 일간이 양인(羊刃)을 가지고 칠살과 합하는 경우. 일부 학파에서 무장(武將)의 명으로 해석하나 자평진전은 이 구조를 복잡하게 본다.

## 8. 정관격 vs 칠살격 비교

| | 정관격 | 칠살격 |
|---|---|---|
| 극의 성격 | 음양 다름 — 부드러운 제어 | 음양 같음 — 강한 압박 |
| 핵심 용신 | 재성·인성 | 식신·상관(제살). 인성은 인이 유정할 때 |
| 재성 역할 | 용신(재생관) | 기신(재생살) |
| 식신 역할 | 큰 의미 없음 | 핵심 용신(식신제살) |
| 상관 역할 | 기신(상관견관) | 제살(원문 근거는 상관격 쪽 문장 — §3) |
| 성격 키워드 | 규범, 명예, 문관 | 권력, 압박, 무관 |

## 9. 학파 간 이견

**이견 ①** 재성생살의 절대성: 자평진전도 재생살을 원칙상 기신으로 보지만 스스로 예외를 든다 — 식신이 인에 막혀 살을 제어하지 못할 때 재가 인을 제거하면 귀격이다(「财以去印存食，便为贵格」, 周丞相 〔戊戌 甲子 丁未 庚戌〕). 신중살경이면 재로 살을 도와 격을 맑힌다(「借财以清格」, 刘运使 〔甲申 乙亥 丙戌 庚寅〕). 徐注도 「身强煞弱，用财滋煞，非不能也」라 한다.

**이견 ②** 상관제살의 유효성: 자평진전은 식신제살을 최상으로 두지만(「煞用食制者，上也」) 칠살격 장에서는 상관제살을 따로 말하지 않는다. 상관격 쪽에서는 살을 차는 상관을 그대로 인정한다(월령 상관의 「伤官带煞，随时可用」, 상관용살인의 「煞因伤而有制，两得其宜」). '상관제살은 불안정하다'는 후대 일부의 견해다.

**이견 ③** 칠살독살: 원문은 제어 없는 칠살을 성격으로 세우지 않는다(「身强七煞逢制」). 신강만으로 살을 감당한다는 독살론은 후대 학파의 말이고, 원문이 식신 없이 인정하는 길은 인(「用印当者」)과 양인(「用刃当煞」)이다.
