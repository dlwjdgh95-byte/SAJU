# 자평진전(子平眞詮) — 정재격(正財格)

> 자평진전 격국론 시리즈 5편.

---

## 1. 정의와 본질

정재격(正財格)은 **월지 본기가 정재**면 성립한다 — 투출하면 더 맑고, 투출하지 않아도 1순위다. 본기가 불투하고 중기·여기의 정재가 투출했거나, 본기가 불투한 채 월지가 낀 삼합이 다 모여 국이 재 무리가 되면 이 격으로 변할 수 있는 **변화 후보**다 — 원문은 본기가 불투하고 중기가 투출하면 중기가 작주한다고 하고(「不透甲而透丙」), 회국도 격을 바꾼다고 한다(「支全卯未，则化为印」, 논용신변화). 원전은 반합도 국으로 본다(「甲不透干而会午会戌，则化为劫」, 赵知府 徐注 「寅午化印为劫」) — 스크립트는 삼합이 다 모일 때만 변화 후보를 내므로 반합은 직접 따진다. 본기도 투출했으면 변하지 않는다(「丙生寅月，午戌会劫，而又或透甲，或透壬，则仍为印而格不破」의 「或透甲」 — 「或透壬」은 다른 투간이 격을 지키는 경우다, SKILL 4-1 ⑤). 국의 정·편은 투간으로만 가리고, 투간이 없거나 정·편이 함께 투간하면 스크립트는 '재격(회국 변화 후보)'처럼 무리로 적는다 — 원문의 「化为印」, 徐注의 「伤化为财」「劫化为食伤」처럼 원전도 무리로 부른다. 辰戌丑未월은 잡기 절차(`35_japgi.md`), 건록·양인·월겁 월령은 `34_geonrok_yangin.md`를 먼저 탄다 (SKILL.md 4-1, errata #20).
정재(正財)란 일간이 음양이 다르게 극(剋)하는 오행이다 — 내가 다스리는 재물.

| 일간 | 정재 |
|---|---|
| 甲(양목) | 己(음토) |
| 乙(음목) | 戊(양토) |
| 丙(양화) | 辛(음금) |
| 丁(음화) | 庚(양금) |
| 戊(양토) | 癸(음수) |
| 己(음토) | 壬(양수) |
| 庚(양금) | 乙(음목) |
| 辛(음금) | 甲(양목) |
| 壬(양수) | 丁(음화) |
| 癸(음수) | 丙(양화) |

**정재의 본질**: 내가 통제하고 관리하는 안정적인 재물. 노력으로 획득하는 현실적 재물이다. 편재(偏財)가 유동적·투기적 재물이라면, 정재는 성실하게 쌓아가는 재물이다.

---

## 2. 성립 조건

월지 본기가 정재면 정재격이 성립한다. 중기·여기의 정재 투출은 변화 후보이고, 본기와 함께 볼 때는 본기가 먼저다. (옛 서술 "월지 장간 중 투출하면 성립"은 투출 우선 규칙이라 폐기 — errata #20)

**정재격의 전제**: 일간이 재를 통제할 수 있어야 한다. 일간이 너무 약하면 재가 오히려 일간을 압박한다(재다신약, 財多身弱).

---

## 3. 용신·희신·기신

### 용신

**① 식상(食傷) — 식상생재(食傷生財)**

식상이 재성을 생하면 재물이 더욱 풍성해진다. 내 능력(식상)으로 재물(재성)을 만드는 형상이다.

```
구조: 일간 →설기→ 식상(食傷) →생→ 정재(財)
```

**② 관성(官星) — 재생관(財生官)**

정재가 관성을 생하는 구조. 재물이 명예(관)를 만드는 형상이다. 정재격에서 관성이 있으면 재관쌍미(財官雙美)라 하여 귀하다.

### 기신

**① 겁재(劫財)·비견(比肩) — 겁재탈재(劫財奪財)**

> 「财轻比重，财透七煞，财格败也」 — 재가 가볍고 비겁이 무겁거나, 재가 칠살을 드러내 생하면 재격이 깨진다(논용신성패구응).

겁재·비견이 정재를 극(比劫剋財)하는데 재가 가벼우면 정재격이 손상된다. 내 재물을 타인이 빼앗아가는 형상이다. 재용식생에 신강하면 비겁 하나는 오히려 유정하다(§8 이견 ①).

**② 칠살 — 재투칠살(財透七煞)**

재가 칠살을 생해 일간을 친다(「财透七煞，财格败也」). 다만 살을 합하거나 제하면 귀격이다 — 「有财带七煞者，或合煞存财，或制煞生财，皆贵格也」(논재, §7).

**③ 식상 없는 신약(身弱)**

일간이 약하고 식상도 없는데 정재만 강하면, 재가 일간을 역극(逆剋)하는 재다신약(財多身弱) 상황이 된다.

---

## 4. 성격(成格)

### 유형 ① 식상생재(食傷生財)

```
예시: 丙火 일간, 酉월(辛金 정재), 천간에 戊土 식신
      丙火→戊土(식신)→辛金(정재) → 식상생재 완성
```

예시는 丙火 일간 酉월로 든다. 甲木 일간의 정재 己土는 본기로는 丑·未(잡기)에만 있어 35번 잡기 절차를 먼저 탄다.

내 능력으로 재물을 만드는 가장 이상적인 정재격 구조.

### 유형 ② 재관쌍미(財官雙美)

```
예시: 丙火 일간, 酉월(辛金 정재), 천간에 癸水 정관
      辛金이 癸水를 생(金生水) → 재관쌍미
      재물로 명예를 이루는 형상
```

---

## 5. 패격(敗格)

### 유형 ① 겁재탈재(劫財奪財)

```
예시: 丙火 일간, 酉월(辛金 정재), 천간에 丁火 겁재
      丁火가 辛金을 극(火克金) → 재가 가볍고 비겁이 무거우면 패격
```

### 유형 ② 재다신약(財多身弱)

```
예시: 甲木 일간이 약한데 재성이 너무 많음
      재가 일간을 역압 → 재물이 있어도 감당 못하는 형상
```

---

## 6. 구격(救格)

### 유형 ① 식상화겁(食傷化劫)

원문이 먼저 드는 구응이다 — 「财逢劫而透食以化之」(논용신성패구응), 「财逢比劫，伤官可解，伤能成格也」(논사흉신능성격). 겁재의 기운을 식상이 받아 재로 돌린다.

```
예시: 丁火 겁재(기신)가 있을 때 戊土 식신·己土 상관이 丁火를 설해 辛金을 생(火生土, 土生金)
      → 겁재가 재를 생하는 쪽으로 돌아섬 → 구격
원전: 汪学士 〔甲子 辛未 辛酉 壬辰〕 「甲透未库，逢辛为劫，壬以化劫生财」(논재)
```

### 유형 ② 관성제겁(官星制劫)

겁재가 재성을 탈취할 때, 관성이 겁재를 극(官克劫)하여 재성을 보호한다(「生官以制之」).

```
예시: 丁火 겁재(기신)가 있을 때 癸水 정관이 丁火를 극(水克火)
      → 겁재 제어 → 재성 보호 → 구격
```

### 유형 ③ 합살·제살(合煞·制煞)

재가 칠살을 생할 때 살을 합하거나 식신으로 제한다 — 「逢煞而食神制煞以生财，或存财而合煞」(논용신성패구응).

### 유형 ④ 인성생신(印星生身)

재다신약 상황에서 인성이 일간을 생하여 일간을 강하게 만들어 재를 감당하게 한다.

---

## 7. 정재격의 특수 구조

**재용식생(財用食生)**: 식상이 재를 생하는 구조. 실업가·사업가의 명.

**재용관성(財用官星)**: 재가 관을 생하는 구조. 재물로 명예를 얻는 형상.

**재용인수(財用印綬)**: 재다신약일 때 인성으로 일간을 보강하는 구조. 역설적이지만 이 경우 인성이 용신이 된다.

**재대칠살(財帶七煞)**: 「有财带七煞者，或合煞存财，或制煞生财，皆贵格也」(논재). 李御史 〔庚辰 戊子 戊寅 甲寅〕는 子월 정재격에 甲木 칠살을 庚金 식신이 제한다(제살생재). 毛状元 〔乙酉 庚辰 甲午 戊辰〕은 辰월 잡기 편재격으로, 乙木이 庚金 칠살을 합해 묶는다(합살존재, 16번).

---

## 8. 학파 간 이견

**이견 ①** 겁재탈재의 절대성: 자평진전도 겁재를 원칙상 기신으로 보지만, 재용식생에 신강하고 관이 드러나지 않으면 비겁 하나는 오히려 유정하다고 한다(「略带一位比劫，益觉有情」, 杨待郎 〔壬寅 壬寅 庚辰 辛巳〕 — 寅 본기 甲은 庚에게 편재지만 재는 정·편을 나누지 않는다: 「财与印不分偏正」). 그 밖에 겁재와 재성의 세력 비교 및 관성의 존재 여부에 따라 판단해야 한다는 견해가 있다.

**이견 ②** 재다신약의 기준: 재다신약의 기준이 학파마다 다르다. 일부는 신강·신약보다 격국의 성패를 더 중시한다.

---

## 9. 정재격 핵심 요약

성격: 식상생재(내 능력으로 재물 생산) 또는 재관쌍미
패격: 겁재탈재(「财轻比重」), 재투칠살(「财透七煞」 — 합살·제살이면 귀격), 재다신약
구격: 식상이 겁재를 화함(「财逢劫而透食以化之」), 관성이 겁재를 제어(「生官以制之」), 식신제살·합살(재대칠살)
