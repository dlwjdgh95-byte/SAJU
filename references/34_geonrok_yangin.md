# 자평진전(子平眞詮) — 건록·월겁격과 양인격

> 자평진전 격국론 시리즈 9편. 월지가 일간의 **록(祿)·양인(陽刃)·겁재(劫財)**일 때 읽는다.
> 원문: 『子平真诠』 论建禄月劫·论建禄月劫取运·论阳刃·论阳刃取运 (徐乐吾 评注本). 원전 명조: `24_japyeong_cases.md`의 〔论建禄月劫〕 11命·〔论阳刃〕 5命.
> 스크립트 `saju_calc.py`의 `격 후보`가 건록격·양인격·월겁격으로 나오면 이 문서로 온다.

## 2. 건록·월겁 — 「禄即是劫」

> 「建禄者，月建逢禄堂也，禄即是劫。或以禄堂透出，即可依以用者，非也。故建禄与月劫，可同一格，不必加分，皆以透干支，别取财官煞食为用。」

**핵심**: 월령의 록·겁은 **용신이 아니다.** 일간을 돕는 기운이 월령을 차지했으니, 투간·회지한 **재·관·살·식상** 가운데서 용신을 따로 취한다. 록이 천간에 투출했다고 그것을 용신으로 삼는 것은 오류다.

### 2-1. 용법별 정리

| 용법 | 원문 | 성립 조건 | 원전 명조 |
|---|---|---|---|
| **용관** | 「禄格用官，干头透出为奇，又要财印相随，不可孤官无辅」 | 정관 투출 + 재(관을 생) 또는 인(상관을 막음)이 따른다 | 金丞相(01, 인이 관을 보호) · 李知府(02, 재가 관을 도움) |
| **삼기** | 「有官而兼带财印者，所谓身强值三奇，尤为贵气。…只要以官隔之，使财印两不相伤，其格便大」 | 재·관·인이 모두 있고, **관이 재와 인 사이**에 있어 재가 인을 깨지 않는다 | 王少师(03) |
| **용재** | 「禄劫用财，须带食伤，盖月令为劫而以财作用，二物相克，必以伤食化之，始可转劫生财」 | 식상이 겁재와 재 사이를 잇는다(통관) | 张都统(04) |
| **화겁** | 「至于化劫为财，与化劫为生，尤为秀气」 | 록겁이 회국해 재(化劫为财)나 식상(化劫为生)으로 바뀐다 | 己未·己巳·丁未·辛丑(원문 예시, 24번 미수록 — 巳丑 금국 → 재) · 高尚书(05, 申子 수국 → 식상) |
| **용살** | 「禄劫用煞，必须制伏」 | 식신이나 회국으로 칠살을 제복 | 娄参政(06) |
| **용살 + 재** | 「至用煞而又逢财，本为不美，然能去煞存财，又成贵格」 | 합살존재 | 袁内阁(07) |
| **용식상** | 「其禄劫之格，无财官而用伤食，泄其太过，亦为秀气。唯春木秋金，用之则贵，盖木逢火则明，金生水则灵」 | 재관이 없고 식상으로 설기. **봄 木·가을 金**일 때 귀 | 张状元(08, 木火通明) · 09(金水相涵) |
| **관살 경출** | 「更有禄劫而官煞竞出，必取清方为贵格」 | 합살유관·제살유관으로 하나를 덜어낸다 | 一平章(10) |
| **쟁관** | 「倘或两官竞出，亦须制伏，所谓争正官不可无伤也」 | 정관 둘 이상이면 상관으로 하나를 제어 | — |
| **관 + 상관** | 「然亦有官伤并透而贵者，何也？如己酉、乙亥、壬戌、庚子，庚合乙而去伤存官，王总兵命也」 | 고관무보는 격이 작고 상관이 끼면 깨지기 쉬우나, 상관이 합거되면 귀 | 王总兵(11) |
| **용재·식상 없음** | 「用财而不透伤食，便难于发端，然干头透一位而不杂，地支根多，亦可取富，但不贵耳」 | 재가 하나만 맑게 투출하고 지지 뿌리가 많으면 부(富)는 가능 | — |
| **관살 과중** | 「用官煞重而无制伏，运行制伏，亦可发财，但不可官煞太重，致令身危也」 | 원국에 제복이 없으면 제복하는 운에서 발한다 | — |

### 2-2. 취운 (论建禄月劫取运)

| 원국 용법 | 원문 |
|---|---|
| 용관·인이 보호 | 「禄劫用官，印护者喜财，怕官星之逢合，畏七煞之相乘。伤食不能为害，劫比未即为凶。」 |
| 용관·재가 생 | 「财生喜印，宜官星之植根，畏伤食之相侮，逢财愈见其功，杂煞岂能无碍？」 |
| 용재 + 식상 | 「禄劫用财而带伤食，财食重则喜印绶，而不忌比肩；财食轻则宜助财，而不喜印比。逢煞无伤，遇官非福。」 |
| 용살 + 식신 제 | 「禄劫用煞食制，食重煞轻，则运宜助煞；食轻煞重，则运喜助食。」 |
| 용살 + 재 | 「若用煞而带财，命中合煞存财，则伤食为宜，财运不忌，透官无虑，身旺亦亨。若命中合财存煞，而用食制，煞轻则助煞，食轻则助食则已。」 |
| 용식상 | 「禄劫而用伤食，财运最宜，煞亦不忌，行印非吉，透官不美。若命中伤食太重，则财运固利，而印亦不忌矣。」 |
| 관살 경출 | 「禄劫而官煞并出，不论合煞留官，存官制煞，运喜伤食，比肩亦宜，印绶未为良图，财官亦非福运。」 |

徐注의 요약: 「月令禄劫，不能为用，随四柱配合，用财官食伤，即与论财官食伤取运相同也」 — 용신을 정한 뒤에는 그 십신 격(11~18번)의 취운을 따른다.

## 3. 양인 — 「刃宜伏制」

> 「阳刃者，劫我正财之神，乃正财之七煞也。禄前一位，惟五阳有之，故为阳刃。不曰劫而曰刃，劫之甚也。刃宜伏制，官煞皆宜，财印相随，尤为贵显。」

### 3-1. 일반 칠살격과 반대로 읽는 곳

> 「夫正官而财印相随美矣，七煞得之，夫乃甚乎？岂知他格以煞能伤身，故喜制伏，忌财印；阳刃用之，则赖以制刃，不怕伤身，故反喜财印，忌制伏也。」

| | 일반 칠살격(12번) | 양인격의 칠살 |
|---|---|---|
| 칠살의 역할 | 일간을 치는 병 | **양인을 제어하는 약(용신)** |
| 식신 제살 | 길(제살) | 원칙적으로 **기피**(「忌制伏」) — 용신인 칠살을 깎는다. 단 살이 지나치게 무거우면 식상으로 덜어내는 것이 귀하다(「煞太重而裁损之」 — 贾平章은 「煞两透而根太重」, 둘 투출에 뿌리도 무겁다) |
| 재성 | 재생살이라 기피 | **길** — 칠살을 살린다 |
| 인성 | 식신으로 제살할 때는 원칙상 기피 — 「煞用食制，不要露财透印…印能去食护煞也」. 단 식신이 지나치게 무거우면 인으로 덜어내 대귀 — 「或印先食后，食太旺而印制，则格成大贵」(脱丞相 壬辰 甲辰 丙戌 戊戌 「食太重而透甲印，以损太过，岂非贵格」 — 24번 论偏官-01 평어 속. 辰월 잡기라 스크립트 1순위는 잡기 식신격이고 칠살격은 2순위다 — 논편관은 칠살을 쓰는 명조로(「辰中暗煞，壬以透之」), 논잡기는 같은 짜임을 식신대살로 읽는다(「又如丙生辰月，透戊为食，而又透壬为煞…譬如食神带煞，煞逢食制，二者皆是美格」). 어느 쪽이든 식신제살 구조다) | **길** — 「反喜财印」 |

⚠️ 양인격에서 「식신제살」을 무조건 길로 읽으면 판정이 뒤집힌다. 먼저 살이 지나치게 무거운지(贾平章처럼 투출과 뿌리가 함께 무거운지) 본다 — 과중하지 않으면 기피, 과중하면 덜어냄(裁损)이 귀. 운도 같다 — 「煞若太重，则运喜身旺印绶，伤食亦不为忌」(§3-4).

### 3-2. 관과 살, 양인 투출

> 「阳刃用官，透刃不虑；阳刃露煞，透刃无成。盖官能制刃，透而不为害；刃能合煞，则有何功？如丙生午月，透壬制刃，而又露丁，丁与壬合，则七煞有贪合忘克之意，如何制刃？故无功也。」

- 양인이 천간에 투출해도 정관을 쓰면 문제없다.
- 칠살을 쓰는데 양인이 투출하면 **양인과 칠살이 합**(甲의 乙庚, 丙의 丁壬, 戊의 己甲, 庚의 辛丙, 壬의 癸戊)해 칠살이 양인을 제어하지 못한다.

### 3-3. 격의 고저

> 「然同是官煞制刃，而格亦有高低，如官煞露而根深，其贵也大；官煞藏而不露，或露而根浅，其贵也小。」

| 명조(24번) | 구조 | 원전 평어 |
|---|---|---|
| 论阳刃-01 〔己酉 丙子 壬寅 丙午〕 | 관 투출·유력, 왕한 재가 생 | 「官透有力，旺财生之，丞相命也」 |
| 论阳刃-02 〔辛酉 甲午 丙申 壬辰〕 | 살 투출·뿌리 얕음, 재·인이 도움 | 「透煞根浅，财印助之，亦丞相命也」 |

### 3-4. 관살 제인에 식상이 낄 때

> 「然亦有官煞制刃带伤食而贵者，何也？或是印护，或是煞太重而裁损之，官煞轻而取清之」

| 명조(24번) | 구조 | 평어 |
|---|---|---|
| 论阳刃-03 穆同知 〔甲午 癸酉 庚寅 戊寅〕 | 상관 癸가 관 丁을 치나 인 戊가 癸를 합거 | 「所谓印护也」 |
| 论阳刃-04 贾平章 〔甲寅 庚午 戊申 甲寅〕 | 칠살 두 개·뿌리 과중 → 식신 庚이 덜어냄 | 「所谓裁损也」 |
| 论阳刃-05 〔丙戌 丁酉 庚申 壬午〕 | 관살 경출, 식신 壬이 관 丁을 합거 → 살만 남음 | 「况阳刃之格，利于留煞，所谓取清也」 |

徐注는 贾平章 명조를 「年月寅午会局，乃印而非刃」이라 하여 양인격으로 보는 데 이견을 단다. 이런 명조는 두 견해를 병기한다.

### 3-5. 丙·戊 午월과 양인 용재

> 「其于丙生午月，内藏己土，可以克水，尤宜带财佩印，若戊生午月，干透丙火，支会火局，则化刃为印，或官或煞，透则去刃存印其格愈清。倘或财煞并透露，则犯去印存煞之忌，不作生煞制煞之例，富贵两空矣。」
>
> 「更若阳刃用财，格所不喜，然财根深而用伤食，以转刃生财，虽不比建禄月劫，可以取贵，亦可就富。不然，则刃与财相搏，不成局矣。」

- 丙 午월: 午 중 己土가 칠살 壬을 극하므로 재·인이 함께 있어야 좋다.
- 戊 午월에 丙이 투출하고 화국이면 양인이 인으로 바뀐다(化刃为印). 이때 재와 살이 함께 투출하면 재가 인을 깨고 살만 남아 실패한다.
- 양인 용재: 재가 뿌리 깊고 식상이 이어줄 때만 성립. 식상이 없으면 양인과 재가 싸운다.

### 3-6. 취운 (论阳刃取运)

| 원국 용법 | 원문 |
|---|---|
| 용관 | 「阳刃用官，则运喜助官，然命中官星根深，则印绶比劫之方，反为美运，但不喜伤食合官耳。」 |
| 용살 | 「阳刃用煞，煞不甚旺，则运喜助煞；煞若太重，则运喜身旺印绶，伤食亦不为忌。」 |
| 관살 병출 | 「阳刃而官煞并出，不论去官去煞，运喜制伏，身旺亦利，财地官乡反为不吉也。」 |
| 용재 | 徐注 「阳刃用财，必须有食伤通关，用食伤则喜行财地，其取运与建禄同」 |

## 4. 판정 절차

```
① 스크립트 격 후보가 건록·양인·월겁인지 확인한다 (월지 辰戌丑未면 35번이 먼저)
② 록·겁·양인 자체를 용신으로 세우지 않는다 — 「禄即是劫」
③ 강약을 먼저 본다 (21번). 월령 록·양인이라도 설기가 심하면 신약이다
   徐注 예: 戊子·戊午·丙辰·戊戌 — 「月令阳刃，泄气太甚，反嫌身弱，须助其刃」
④ 투간·회지한 재·관·살·식상 중 무엇을 쓰는지 §2-1(건록·월겁) 또는 §3(양인) 표에서 찾는다
⑤ 양인격이면 칠살·식신의 길흉을 일반 칠살격과 반대로 본다 (§3-1)
⑥ 용신을 정한 뒤 성패는 19번, 그 십신의 격 파일(11~18번)을 보조로 쓴다
⑦ 24번 원전 명조에서 같은 용법을 찾아 평어와 대조한다 (§2-1·§3-3·§3-4 표)
```
