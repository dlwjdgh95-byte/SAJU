# 자평진전(子平眞詮) — 격국 사례 분석

> 이 문서는 격국론의 이론을 실제 사주 구조에 적용한 사례들을 정리한 것이다.
> 이론 설명용 **구성 사례**다 — 일간·월지·투간만 정한 구조이고 실제 명조가 아니다. 원전 명조와 평어는 `24_japyeong_cases.md`에 있다.
> 격은 월령 본기의 십성이 1순위다(SKILL 4-1). 인은 정·편을 나누지 않는다(「财与印不分偏正」).

## 1. 정관격 사례

### 사례 1-A: 정관격 성격 (관인상생)

```
사주 구조:
甲木 일간, 酉월(본기 辛金 정관이 월간에 투출)
天干: 壬水 편인(시간), 지지 子水에 통근

분석:
月支 酉 본기 辛金 → 甲木 일간의 정관격 성립 (투출로 더 맑다)
壬水 편인이 時干에 투출, 子水에 통근 → 인성 힘 있음 (인은 정·편을 가리지 않는다)
辛金(정관) → 壬水(인) → 甲木(일간): 관인상생 구조 완성
기신(상관·겁재·칠살) 없음

판정: 성격 — 관인상생 구조의 정관격
특징: 학문과 명예의 명. 관직·교육계에서 두각을 나타내는 구조.
```

### 사례 1-B: 정관격 패격 (상관견관)

```
사주 구조:
年: 壬午
月: 辛酉
日: 甲辰 (甲木 일간)
時: 丁卯

분석:
月支 酉中 辛金 정관 투출 → 정관격 성립
時干 丁火 상관 투출, 卯木에 통근 → 상관 힘 있음
丁火(상관)가 辛金(정관)을 극(火克金) → 상관견관 발생

기신 제어 여부 확인:
壬水(年干)가 있으나 丁壬합으로 壬水가 합거됨
→ 壬水의 정인 역할 소멸 → 상관을 제어할 수단 없음

판정: 패격 — 상관견관이 해소되지 않음
특징: 관직에서 충돌이 많고 직업 변동이 잦은 형상.
```

### 사례 1-C: 정관격 구격 (상관패인)

```
사주 구조:
甲木 일간, 酉월(辛金 정관 투출)
天干: 庚金 칠살, 丁火 상관 / 지지에 丑

분석:
辛金 정관 투출 → 정관격 성립 (庚金 칠살도 투출해 관살혼잡의 소지가 있다)
丁火 상관 투출 → 상관견관 발생 → 패격 위기
癸水(丑中 장간) 또는 壬水 인성이 있어야 구격 가능

추가 조건: 만약 年干에 壬水가 있다면
壬水(편인)가 丁火(상관)를 극(水克火) → 상관 제어
→ 상관패인 구조 완성 → 구격 → 패중취귀

판정: 구격 조건부 — 인성의 존재 여부에 따라 달라짐
```

## 2. 칠살격 사례

### 사례 2-A: 칠살격 성격 (식신제살)

```
사주 구조:
甲木 일간, 申월(본기 庚金 칠살 투출), 일지도 申
天干: 丙火 식신 둘(연간·시간), 지지 午火에 통근

분석:
月支 申 본기 庚金이 月干에 투출 → 甲木 일간의 칠살격 성립
庚金(칠살) 강함 — 월지·일지 모두 申
丙火(식신) 투출, 午火에 통근 → 식신 힘 있음
丙火(식신)가 庚金(칠살)을 극(火克金) → 식신제살 완성
재성 없어 재성생살 위험 없음

판정: 성격 — 식신제살 구조의 칠살격
특징: 강한 살을 식신이 완전히 제어하여 권위 있는 명.
```

### 사례 2-B: 칠살격 패격 (재성생살)

```
사주 구조:
甲木 일간, 申월(본기 庚金 칠살 투출)
天干: 戊土 편재 둘(연간·시간), 지지 戌·午에 통근

분석:
庚金 칠살 투출 → 칠살격 성립
戊土(편재)가 年·時干에 투출, 戌·午에 통근 → 재성 강함
戊土(편재)가 庚金(칠살)을 생(土生金) → 재성생살 발생
칠살이 더욱 강해짐 → 甲木 일간 압박 심화
식신이 없어 살을 제어할 수단 없음

판정: 패격 — 재성생살이 해소되지 않음
특징: 재물이 오히려 화를 불러오는 형상. 사업 실패의 패턴.
```

## 3. 정인격 사례

### 사례 3-A: 정인격 성격 (관인상생)

```
사주 구조:
壬水 일간, 酉월(본기 辛金 정인 투출)
天干: 己土 정관

분석:
月支 酉 본기 辛金 → 壬水 일간의 정인격 성립
己土(정관)가 辛金(정인)을 생(土生金) → 辛金이 壬水를 생(金生水)
→ 관인상생 완성

판정: 성격 — 관인상생 구조의 정인격
특징: 학문으로 관직에 오르는 구조.
```

### 사례 3-B: 정인격 패격 (재파인)

```
사주 구조:
壬水 일간, 酉월(辛金 정인 투출)
天干: 甲木 식신, 丙火 편재

분석:
辛金(정인) 투출 → 정인격 성립
丙火(편재)가 辛金(정인)을 극(火克金) → 재파인 발생
甲木(식신)이 丙火를 생하여 재성을 더욱 강하게 함
정인이 재성에 의해 파괴됨

판정: 패격 — 재파인 해소 안 됨
구격 조건: 비겁(壬水 동류 또는 癸水)이 있어 丙火 재성을 제어하면 구격 가능
```

## 4. 식신격 사례

### 사례 4-A: 식신격 성격 (식신생재)

```
사주 구조:
甲木 일간, 巳월(본기 丙火 식신 투출)
天干: 戊土 편재 있음
地支: 뿌리 있음

분석:
丙火(식신) 투출, 巳火에 통근 → 식신 힘 있음
戊土(편재)가 있음, 지지에 뿌리
丙火(식신)가 戊土(편재)를 생(火生土) → 식신생재 완성
인(壬水·癸水) 없음 → 탈식(효신도식) 위험 없음

판정: 성격 — 식신생재 구조
특징: 표현 능력으로 재물을 만드는 복록(福祿)의 명.
```

### 사례 4-B: 식신격 패격 (효신도식)

```
사주 구조:
甲木 일간, 巳월(본기 丙火 식신 투출)
天干: 壬水 편인 있음

분석:
丙火(식신) 투출 → 식신격 성립
壬水(편인)가 丙火(식신)를 극(水克火) → 효신도식 발생
식신의 생산·복록 기능 박탈

구격 조건:
戊土(재성)가 있으면 戊土가 壬水(편인)를 극(土克水)
→ 편인 제어 → 식신 보호 → 구격

판정: 패격 (구격 조건 없을 때)
특징: 노력해도 결실이 사라지는 형상. 의식주 불안정.
```

## 5. 상관격 사례

### 사례 5-A: 상관격 성격 (상관생재)

```
사주 구조:
庚金 일간, 子월(癸水 상관 투출)
天干: 甲木 편재 있음
관성 없음

분석:
癸水(상관) 투출, 子水에 통근 → 상관격 성립
甲木(편재)가 있음, 지지에 뿌리
癸水(상관)가 甲木(편재)를 생(水生木) → 상관생재 완성
정관 없어 상관견관 위험 없음

판정: 성격 — 상관생재 구조
특징: 날카로운 능력으로 재물을 만드는 형상.
```

### 사례 5-B: 금수상관 성격 (상관격 + 관성)

```
사주 구조:
庚金 일간, 子월(癸水 상관 투출)
天干: 丁火 정관 있음

분석:
癸水(상관) 투출 → 상관격 성립
丁火(정관)가 있음

일반 상관격: 상관견관으로 패격
그러나 금수상관(庚金 일간, 水 상관) 특례:
"금수상관희견관(金水傷官喜見官)"
→ 금수 상관격에서 관성은 오히려 격을 완성

판정: 성격 — 금수상관의 특례 적용
특징: 금수 상관의 독특한 구조. 지성과 권위가 결합된 명.
```

### 사례 5-C: 상관격 패격 (상관견관)

```
사주 구조:
甲木 일간, 午월(丁火 상관 투출)
天干: 辛金 정관 있음
인성 없음

분석:
丁火(상관) 투출 → 상관격 성립
辛金(정관)이 있음
丁火(상관)가 辛金(정관)을 극(火克金) → 상관견관 발생
인성이 없어 상관을 제어할 수단 없음

판정: 패격 — 상관견관 해소 불가
구격 조건: 壬水·癸水 인성이 있으면 인성이 상관 제어 → 상관패인 → 구격
```

## 6. 복합 사례 — 패중취귀(敗中取貴)

### 사례 6-A: 정관격 패중취귀

```
사주 구조:
辛金 일간, 巳월(본기 丙火 정관 투출)
天干: 壬水 상관, 戊土 정인, 甲木 정재

분석 순서:

① 格 결정:
   巳 본기 丙火 → 辛金 일간의 정관격 성립

② 기신 확인:
   壬水(상관)가 丙火(정관)를 극(水克火) → 상관견관 → 패격 위기

③ 구응:
   戊土(정인)가 壬水(상관)를 극(土克水) → 상관 제어 → 구격
   甲木(정재)이 丙火(정관)를 생(木生火) → 재생관 → 격 보강

④ 판정: 패중취귀
   상관이 정관을 극하는 패격 원인이 있으나
   인성이 상관을 제어하고 재성이 정관을 생하는 구격이 이루어짐
   → 관·상관·인성·재성의 복합 구조 → 오히려 귀한 명
```

## 7. 格局 판단 Quick Reference

### 월지별 장간과 1순위 격

| 월지 | 장간 (여기→중기→본기, 지장간가) | 1순위 격을 정하는 글자 |
|---|---|---|
| 寅 | 戊·丙·甲 | 본기 甲 |
| 卯 | 乙 | 본기 乙 |
| 辰 | 乙·癸·戊 | 본기 戊 — 잡기: 투출·고의 오행 투간·회지를 먼저 본다(35번) |
| 巳 | 戊·庚·丙 | 본기 丙 |
| 午 | 己·丁 | 본기 丁 |
| 未 | 丁·乙·己 | 본기 己 — 잡기: 투출·고의 오행 투간·회지를 먼저 본다(35번) |
| 申 | 戊·壬·庚 | 본기 庚 |
| 酉 | 辛 | 본기 辛 |
| 戌 | 辛·丁·戊 | 본기 戊 — 잡기: 투출·고의 오행 투간·회지를 먼저 본다(35번) |
| 亥 | 甲·壬 | 본기 壬 |
| 子 | 癸 | 본기 癸 |
| 丑 | 癸·辛·己 | 본기 己 — 잡기: 투출·고의 오행 투간·회지를 먼저 본다(35번) |

※ 격은 일간 기준 본기의 십성이다(예: 酉월 본기 辛 → 甲 일간 정관격, 乙 일간 칠살격, 壬 일간 정인격). 본기가 일간의 비견·겁재면 건록·양인·월겁 절차(34번)를 탄다. 기준표와 월률분야 차이는 26번 §2-2.

### 格局별 핵심 판단 요약

```
정관격: 상관 있는가? (있으면 패격 위험) → 인성이 상관 제어하는가?
칠살격: 식신 있는가? (없으면 패격 위험) → 재성이 살 생하지 않는가?
정인격: 재성 있는가? (있으면 패격 위험) → 비겁이 재성 제어하는가?
편인격: 정인격과 같이 본다(인은 정·편을 나누지 않는다) → 재성이 인을 깨는가? 신강인왕이면 식상 설기가 용신 (편인격에 식신이 투출한 것을 효신도식이라 하지 않는다: 「见偏印透食，不以为泄身之秀，而以为枭神夺食」는 그렇게 읽는 오류를 꾸짖는 말)
정재격: 겁재 있는가? (있으면 탈재 위험) → 관성이 겁재 제어하는가?
편재격: 겁재 있는가? + 칠살 있는가? → 각각 제어하는가?
식신격: 인(정·편) 있는가? (있으면 탈식 위험 — 「食神虽逢正印，亦谓夺食」) → 재성이 인 제어하는가?
상관격: 정관 있는가? (있으면 상관견관) → 인성이 상관 제어하는가?
         금수상관이면 정관이 있어도 OK
```

## 8. 자평진전 원전의 핵심 명구(名句)

자평진전 원문(徐乐吾 评注본과 글자 대조)에서 격국론의 뼈대가 되는 문장들:

> 「八字用神，专求月令」 (논용신)

> 「七煞喜食神以制伏，忌财印以资扶」 (논용신)

> 「成中有败，必是带忌；败中有成，全凭救应」 (논용신성패구응)

> 「伤官见官，为祸百端，而金水见之，反为秀气」 (논용신배기후득실)

> 「食神虽逢正印，亦谓夺食」 (논용신배기후득실)

> 「煞以攻身，似非美物，而大贵之格，多存七煞」 (논편관)

> 「若印轻财重，又无劫财以救，则为贪财破印，贫贱之局也」 (논인수)

> 「财与印不分偏正」 (논인수)
