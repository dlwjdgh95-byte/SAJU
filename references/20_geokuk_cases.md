# 자평진전(子平眞詮) — 격국 사례 분석

> 이 문서는 격국론의 이론을 사주에 적용한 사례들을 정리한 것이다.
> **성격 사례는 원전 명조**(자평진전 본문이 직접 든 명조와 평어 — `24_japyeong_cases.md`)이고, **패격 사례는 구성 명조**다. 구성 명조는 원전이 패격 명조를 거의 들지 않아 만든 것으로, 1900~2100년 달력에 실제로 있는 4기둥(월두법·시두법이 맞는)만 골랐다. 실존 인물의 명조가 아니다.
> 판정은 논용신성패구응의 성(成)·패(败)·구응(救应) 문장을 따른다. 격은 월령 본기의 십성이 1순위다(SKILL 4-1). 인은 정·편을 나누지 않는다(「财与印不分偏正」).

## 1. 정관격 사례

### 사례 1-A: 정관격 성격 — 재·인을 함께 쓴다 (원전 薛相公)

```
사주: 甲申 壬申 乙巳 戊寅  (乙木 일간)

분석:
月支 申 본기 庚金 = 乙의 정관 → 정관격 (庚은 불투)
月干 壬水 정인, 時干 戊土 정재 투출 — 재가 관을 생하고 인이 일간을 돕는다
壬(月干)과 戊(時干) 사이에 일간 乙이 끼어 있어 재가 인을 깨지 않는다

원문: 「壬印戊财，以乙隔之，水与土不相碍，故为大贵」 (논정관)
판정: 성격 — 재·인 병용(「官逢财印…官格成也」, 논용신성패구응)
```

### 사례 1-B: 정관격 패격 — 상관견관 (구성 명조)

```
사주: 辛卯 丁酉 甲午 甲戌  (甲木 일간)

분석:
月支 酉 본기 辛金 = 甲의 정관, 年干에 투출 → 정관격
月干 丁火 상관이 年干 辛金 바로 옆에 투출, 日支 午·時支 戌에 통근 → 상관이 관을 친다
인(壬·癸)이 천간에도 지지 장간에도 없다 → 상관을 막을 글자가 없다
재(戊)는 戌 속에만 있어 「透财…伤官生财来生官」으로 풀 수도 없다

원문: 「官逢伤克刑冲，官格败也」, 구응은 「官逢伤而透印以解之」 (논용신성패구응)
판정: 패격 — 구응이 없다
```

### 사례 1-C: 정관격 구격 — 상관을 인으로 막는다 (원전 宣参国)

```
사주: 己卯 辛未 壬寅 辛亥  (壬水 일간)

분석:
月支 未(잡기) 중 己土 정관이 年干에 투출 → 잡기 정관격
地支 亥·卯·未 목국 = 壬의 식상 → 상관이 관을 칠 형세(遇伤)
月干·時干의 두 辛金 정인이 목국을 제어하고 일간을 생한다 → 상관패인

원문: 「未中己官透干用清，支会木局，两辛解之，是遇伤而佩印也」 (논정관)
판정: 패중유성 — 「官逢伤而透印以解之」
```

## 2. 칠살격 사례

### 사례 2-A: 칠살격 성격 — 식신제살 (원전)

```
사주: 乙亥 乙酉 乙卯 丁丑  (乙木 일간)

분석:
月支 酉 본기 辛金 = 乙의 칠살 → 칠살격 (辛은 불투)
時干 丁火 식신이 살을 제어한다
年干·月干 乙 비견, 日支 卯·年支 亥 → 일간이 튼튼해 살과 식신을 감당한다

원문: 「煞用食制者，上也，煞旺食强而身健，极为贵格。如乙亥、乙酉、乙卯、丁丑，极等之贵也」 (논편관)
판정: 성격 — 「身强七煞逢制，煞格成也」
```

### 사례 2-B: 칠살격 패격 — 재가 살을 돕고 제어가 없다 (구성 명조)

```
사주: 戊戌 庚申 甲申 戊辰  (甲木 일간)

분석:
月支 申 본기 庚金 = 甲의 칠살, 月干에 투출 → 칠살격. 日支도 申
年干·時干 戊土 편재가 戌·辰에 통근 → 재가 살을 생한다
식신·상관(丙·丁)이 천간에 없고, 인(壬·癸)도 辰 속 癸뿐이라 살을 받아 줄 글자가 약하다
일간 甲은 辰 속 乙 말고는 뿌리가 없다

원문: 「七煞逢财无制，七煞格败也」 (논용신성패구응)
판정: 패격
참고: 재가 늘 기신인 것은 아니다 — 식신이 막혔을 때 재로 인을 치거나(周丞相 「财以去印存食」),
      신중살경이면 재로 살을 돕는다(刘运使 甲申 乙亥 丙戌 庚寅 「借财以清格」, 논편관). 12번 §3.
```

## 3. 인수격 사례

### 사례 3-A: 인수격 성격 — 인에 관이 투출 (원전 张参政)

```
사주: 丙寅 戊戌 辛酉 戊子  (辛金 일간)

분석:
月支 戌(잡기) 중 戊土 정인이 月干·時干에 투출 → 잡기 인수격
年干 丙火 정관 투출, 寅에 통근 → 관이 맑다
일간 辛은 酉에 앉고 인이 두터워 신왕인강

원문: 「有印而透官者，正官不独取其生印，而即可以为用…故身旺印强，不愁太过，只要官星清纯，如丙寅、戊戌、辛酉、戊子，张参政之命是也」 (논인수)
판정: 성격 — 「官印双全…印格成也」
```

### 사례 3-B: 인수격 패격 — 탐재파인 (구성 명조)

```
사주: 辛酉 辛卯 丙申 戊戌  (丙火 일간)

분석:
月支 卯 본기 乙木 = 丙의 정인 → 인수격 (乙은 불투)
年干·月干 辛金 정재가 酉·申에 통근하고, 時干 戊土 식신이 재를 생한다 → 재가 무겁다
年支 酉가 月支 卯를 충한다 → 인이 더 상한다
비겁(丙·丁)이 천간에 없어 재를 막아 줄 글자가 없다(戌 속 丁뿐)

원문: 「若印轻财重，又无劫财以救，则为贪财破印，贫贱之局也」 (논인수), 「印轻逢财…印格败也」 (논용신성패구응)
판정: 패격 — 구응(「印逢财而劫财以解之，或合财而存印」)이 없다
```

### 사례 3-C: 인이 무거우면 재가 용신 (원전 汪侍郎)

```
사주: 辛酉 丙申 壬申 辛亥  (壬水 일간)

분석:
月支 申 본기 庚金 = 壬의 편인 → 인수격(편인 — 인은 정·편을 나누지 않는다)
年干·時干 辛金 정인, 地支 申·申·酉 → 인이 매우 무겁고 일간도 亥에 뿌리
月干 丙火 편재가 인을 덜어 낸다

원문: 「有印多而用财者，印重身强，透财以抑太过，权而用之，只要根深，无防财破。如辛酉、丙申、壬申、辛亥，汪侍郎命是也」 (논인수)
판정: 성격 — 3-B와 같은 '인 + 재'라도 인의 경중에 따라 정반대다
```

## 4. 식신격 사례

### 사례 4-A: 식신격 성격 — 식신생재 (원전 谢阁老)

```
사주: 己未 壬申 戊子 庚申  (戊土 일간)

분석:
月支 申 본기 庚金 = 戊의 식신, 時干에 투출 → 식신격
月干 壬水 편재 투출, 日支 子에 통근 → 식신이 재를 생한다
年干 己·年支 未로 일간도 뿌리가 있다

원문: 「食神生财，美格也。财要有根…如身强食旺而财透，大贵之格…己未、壬申、戊子、庚申，谢阁老之命是也」 (논식신)
판정: 성격
```

### 사례 4-B: 식신격 패격 — 효신탈식 (구성 명조)

```
사주: 辛酉 辛卯 癸酉 癸丑  (癸水 일간)

분석:
月支 卯 본기 乙木 = 癸의 식신 → 식신격 (乙은 불투)
年干·月干 辛金 편인이 酉·酉·丑에 통근 → 인이 식신을 친다. 年支·日支 酉가 月支 卯를 충한다
재(丙·丁)가 없어 「生财以护食」이 안 되고, 칠살(己)은 丑 속에만 있어 「就煞以成格」도 안 된다
봄의 癸水라 조후 예외(夏木)도 아니다

원문: 「食神逢枭…食神格败也」, 구응은 「食逢枭而就煞以成格，或生财以护食」 (논용신성패구응)
판정: 패격
```

### 사례 4-C: 여름 목(夏木)은 인이 식신을 해치지 않는다 (원전 钱参政)

```
사주: 丙午 癸巳 甲子 丙寅  (甲木 일간)

분석:
月支 巳 본기 丙火 = 甲의 식신, 年干·時干에 투출 → 식신격
月干 癸水 정인이 투출해 4-B와 같은 '식신 + 인' 구조다
그러나 여름 불이 왕해 목이 탈 지경이라, 인은 식신을 빼앗기보다 조후를 맞춘다

원문: 「至于食神忌印，夏火太炎而木焦，透印不碍，如丙午、癸巳、甲子、丙寅，钱参政命是也」 (논식신),
      「食神虽逢正印，亦谓夺食，而夏木火盛，轻用之亦秀而贵」 (논용신배기후득실)
판정: 성격 — 식신에 인이 붙었다고 곧 탈식 패격으로 읽지 않는다
```

## 5. 상관격 사례

### 사례 5-A: 상관격 성격 — 상관생재 (원전 史春芳)

```
사주: 壬午 己酉 戊午 庚申  (戊土 일간)

분석:
月支 酉 본기 辛金 = 戊의 상관 → 상관격 (辛은 불투, 時干 庚 식신 투출)
年干 壬水 편재 투출 → 식상이 재를 생한다
일간 戊는 午·午에 뿌리(午 중 丁·己), 月干 己 겁재 → 신강

원문: 「伤官生财，则以伤官为生官之具，转凶为吉，故最利。只要身强而有根，便为贵格，如壬午、己酉、戊午、庚申，史春芳命也」 (논상관)
판정: 성격
주의: 겨울 금(冬金)의 상관생재는 귀하지 않다 — 「伤官生财，冬金不贵，以冻水不能生木」 (논상관),
      「伤官用财…而用之冬水，即使小富，亦多不贵」 (논용신배기후득실). 庚 일간 子월에 甲 재를 쓰는 구조를 성격 예로 들지 않는다
```

### 사례 5-B: 금수상관은 관을 쓸 수 있다 — 조건이 있다 (원전 丞相)

```
사주: 戊申 甲子 庚午 丁丑  (庚金 일간)

분석:
月支 子 본기 癸水 = 庚의 상관 → 상관격 (癸는 불투 — 「藏癸」)
時干 丁火 정관 투출, 日支 午에 통근(관이 녹에 앉음)
年干 戊土 편인·月干 甲木 편재가 관을 돕는다(「戊甲为辅」)
상관 癸가 천간에 나오지 않아 관과 함께 투출하지 않았다

원문: 「有伤官用官者，他格不用，金水独宜，然要财印为辅，不可伤官并透。如戊申、甲子、庚午、丁丑，藏癸露丁，戊甲为辅，官又得禄，所以为丞相之格。若孤官无辅，或官伤并透，则发福不大矣」 (논상관)
판정: 성격 — 금수상관이라도 재·인의 보좌가 없거나 상관과 관이 함께 투출하면 크게 발복하지 못한다
```

### 사례 5-C: 상관격 패격 — 상관견관 (구성 명조)

```
사주: 乙卯 己卯 壬午 癸卯  (壬水 일간)

분석:
月支 卯 본기 乙木 = 壬의 상관, 年干에 투출 → 상관격. 地支에 卯가 셋
月干 己土 정관이 年干 乙木 바로 옆에 투출(日支 午 중 己에 통근) → 상관견관
금수상관이 아니고(水 일간·木 상관), 인(庚·辛)이 천간·지지 어디에도 없다
재(丙·丁)는 午 속 丁뿐이라 「透财…伤官生财来生官」으로 풀리지 않는다

원문: 「伤官非金水而见官…伤官格败也」 (논용신성패구응)
판정: 패격
```

## 6. 복합 사례 — 패중유성(敗中有成)

### 사례 6-A: 정관격 — 상관과 재가 함께 왔는데 두 인이 나눠 막는다 (원전 范太傅)

```
사주: 丁丑 壬寅 己巳 丙寅  (己土 일간)

분석 순서:

① 格 결정: 月支 寅 본기 甲木 = 己의 정관 → 정관격 (甲은 불투, 時支 寅도 정관)

② 기신 확인:
   地支 巳·丑이 금국 쪽으로 모인다 = 己의 식상 → 상관이 관을 칠 형세
   月干 壬水 정재 투출 → 재가 인을 깰 형세

③ 구응:
   年干 丁火 편인이 壬水와 합해 재를 묶는다(丁壬합)
   時干 丙火 정인이 금(상관)을 제어해 관을 맑게 한다

④ 판정: 패중유성
   원문: 「支具巳丑，会金伤官，丙丁解之，透壬岂非破格？却不知丙丁并透，用一而足，以丁合壬而财去，
          以丙制伤而官清，无情而愈有情」 (논정관)
```

## 7. 格局 판단 Quick Reference

### 월지별 장간과 1순위 격

| 월지 | 장간 (여기→중기→본기, 지장간가) | 1순위 격을 정하는 글자 |
|---|---|---|
| 寅 | 戊·丙·甲 | 본기 甲 |
| 卯 | 乙 | 본기 乙 |
| 辰 | 乙·癸·戊 | 본기 戊 — 잡기: 투출·고의 오행 투간·회지를 먼저 본다(35번) |
| 巳 | 戊·庚·丙 | 본기 丙 |
| 午 | 己·丁 | 본기 丁 |
| 未 | 丁·乙·己 | 본기 己 — 잡기: 투출·고의 오행 투간·회지를 먼저 본다(35번) |
| 申 | 戊·壬·庚 | 본기 庚 |
| 酉 | 辛 | 본기 辛 |
| 戌 | 辛·丁·戊 | 본기 戊 — 잡기: 투출·고의 오행 투간·회지를 먼저 본다(35번) |
| 亥 | 甲·壬 | 본기 壬 |
| 子 | 癸 | 본기 癸 |
| 丑 | 癸·辛·己 | 본기 己 — 잡기: 투출·고의 오행 투간·회지를 먼저 본다(35번) |

※ 격은 일간 기준 본기의 십성이다(예: 酉월 본기 辛 → 甲 일간 정관격, 乙 일간 칠살격, 壬 일간 정인격). 다만 월지가 일간의 **록지·양인**이면 본기가 인성이어도 건록·양인 절차(34번)를 먼저 탄다 — 戊 일간 巳월은 건록, 戊 일간 午월은 양인, 己 일간 午월은 건록이다(본기 丙·丁은 인성). 음간이 본기 겁재 월에 나면 월겁(34번). 辰戌丑未월은 잡기 절차(35번). 기준표와 월률분야 차이는 26번 §2-2.

### 格局별 핵심 판단 요약

```
정관격: 상관 있는가? (있으면 패격 위험) → 인성이 상관 제어하는가? 재·인을 함께 쓰면 서로 막지 않는가?
칠살격: 식신 있는가? (없으면 패격 위험) → 재성이 살 생하지 않는가? (신중살경이면 재가 살을 도와도 된다)
인수격: 인이 가벼운데 재가 무거운가? (있으면 패격 — 비겁이 재를 막는가?) 인이 무거우면 재가 오히려 용신
        편인 월령에 식신이 투출한 것은 효신탈식이 아니라 설수(泄秀)다: 「见偏印透食，不以为泄身之秀，而以为枭神夺食」는 그렇게 읽는 오류를 꾸짖는 말
정재격: 겁재 있는가? (있으면 탈재 위험) → 관성이 겁재 제어하는가?
편재격: 겁재 있는가? + 칠살 있는가? → 각각 제어하는가?
식신격: 인(정·편) 있는가? (있으면 탈식 위험 — 「食神虽逢正印，亦谓夺食」. 여름 木은 예외: 「而夏木火盛，轻用之亦秀而贵」) → 재성이 인 제어하는가? 칠살로 격을 바꾸는가?
        단 여름 목(夏木)은 예외: 「而夏木火盛，轻用之亦秀而贵」, 「夏火太炎而木焦，透印不碍」
상관격: 정관 있는가? (있으면 상관견관) → 인성이 상관 제어하는가? 재가 제자리에서 관을 생하는가?
        금수상관은 관을 쓸 수 있다 — 단 재·인이 보좌하고 상관과 관이 함께 투출하지 않을 때(「然要财印为辅，不可伤官并透」)
        겨울 금의 상관생재는 귀하지 않다(「伤官生财，冬金不贵」)
```

## 8. 자평진전 원전의 핵심 명구(名句)

자평진전 원문(徐乐吾 评注본과 글자 대조)에서 격국론의 뼈대가 되는 문장들:

> 「八字用神，专求月令」 (논용신)

> 「七煞喜食神以制伏，忌财印以资扶」 (논용신)

> 「成中有败，必是带忌；败中有成，全凭救应」 (논용신성패구응)

> 「伤官见官，为祸百端，而金水见之，反为秀气」 (논용신배기후득실)

> 「食神虽逢正印，亦谓夺食，而夏木火盛，轻用之亦秀而贵」 (논용신배기후득실)

> 「煞以攻身，似非美物，而大贵之格，多存七煞」 (논편관)

> 「若印轻财重，又无劫财以救，则为贪财破印，贫贱之局也」 (논인수)

> 「财与印不分偏正」 (논인수)
