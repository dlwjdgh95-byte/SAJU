# 자평진전(子平眞詮) — 편인격(偏印格)

> 자평진전 격국론 시리즈 4편. 편인격은 정인격보다 편벽하고 특수한 성질을 가진다.

---

## 1. 정의와 본질

편인격(偏印格)은 **월지 본기가 편인**이면 성립한다 — 투출하면 더 맑고, 투출하지 않아도 1순위다. 본기가 불투하고 중기·여기의 편인이 투출했거나, 본기가 불투한 채 월지가 낀 삼합이 다 모여 국이 인수 무리가 되면 이 격으로 변할 수 있는 **변화 후보**다 — 원문은 본기가 불투하고 중기가 투출하면 중기가 작주한다고 하고(「不透甲而透丙」), 회국도 격을 바꾼다고 한다(「支全卯未，则化为印」, 논용신변화). 원전은 반합도 국으로 본다(「甲不透干而会午会戌，则化为劫」, 赵知府 徐注 「寅午化印为劫」) — 스크립트는 삼합이 다 모일 때만 변화 후보를 내므로 반합은 직접 따진다. 본기도 투출했으면 변하지 않는다(「丙生寅月，午戌会劫，而又或透甲，或透壬，则仍为印而格不破」의 「或透甲」 — 「或透壬」은 다른 투간이 격을 지키는 경우다, SKILL 4-1 ⑤). 국의 정·편은 투간으로만 가리고, 투간이 없거나 정·편이 함께 투간하면 스크립트는 '인수격(회국 변화 후보)'처럼 무리로 적는다 — 원문의 「化为印」, 徐注의 「伤化为财」「劫化为食伤」처럼 원전도 무리로 부른다. 辰戌丑未월은 잡기 절차(`35_japgi.md`), 건록·양인·월겁 월령은 `34_geonrok_yangin.md`를 먼저 탄다 (SKILL.md 4-1, errata #20).
편인(偏印)이란 일간을 음양이 같게 생(生)하는 오행이다.

| 일간 | 편인 |
|---|---|
| 甲(양목) | 壬(양수) |
| 乙(음목) | 癸(음수) |
| 丙(양화) | 甲(양목) |
| 丁(음화) | 乙(음목) |
| 戊(양토) | 丙(양화) |
| 己(음토) | 丁(음화) |
| 庚(양금) | 戊(양토) |
| 辛(음금) | 己(음토) |
| 壬(양수) | 庚(양금) |
| 癸(음수) | 辛(음금) |

**편인의 본질**: 정인이 따뜻하고 정통적인 어머니라면, 편인은 계모·이모처럼 편벽하고 특수한 생조다. 기예(技藝)·종교·철학·특수 학문과 연결된다.

**편인에 붙는 이름 — 효신(梟神)**

식신격에 편인이 와서 식신을 극하는 것을 효신탈식(枭神夺食), 흔히 효신도식(梟神盜食)이라 한다.

효(梟)는 올빼미를 뜻하며, 어미를 잡아먹는 새로 비유된다. 이 이름은 **월령이 식신인 격**에서 다른 자리의 편인이 식신을 극할 때 쓴다 — 徐注 「食神逢枭者，月令食神，别支见枭，为枭神夺食，宜用财制枭以护食」(논용신). 이름은 편인에 붙지만 자평진전은 정인도 같다고 한다(「食神虽逢正印，亦谓夺食」, 논용신배기후득실 — 같은 문장이 「而夏木火盛，轻用之亦秀而贵」로 여름 木의 예외를 단다).

**월령이 편인이고 식신이 투출한 것은 효신도식이 아니다.** 원문은 이것을 효신도식으로 읽는 것을 월령을 모르는 잘못이라 한다 — 「见偏印透食，不以为泄身之秀，而以为枭神夺食，宜用财制，与食神逢枭同论…此皆由不知月令而妄论之故也」(논용신). 徐注: 「偏印透食者，月令偏印滋生日元，食神为泄身之秀，忌见财星」. 편인격의 식신은 신강한 일간의 기운을 빼어나게 설하는 상신이고, 이때 꺼리는 것은 재성이다.

## 2. 성립 조건

월지 본기가 편인이면 편인격이 성립한다. 중기·여기의 편인 투출은 변화 후보이고, 본기와 함께 볼 때는 본기가 먼저다. (옛 서술 "월지 장간 중 투출하면 성립"은 투출 우선 규칙이라 폐기 — errata #20)

**편인격과 정인격의 구별**: 자평진전은 인을 정·편으로 나누지 않는다 — 「正偏同为美格，故财与印不分偏正」(논인수). 정인·편인이 함께 있어도 관살혼잡처럼 격이 탁해진다고 보지 않는다. '인성혼잡'은 후대 학파의 말이다.

## 3. 용신·희신·기신

### 용신

**① 관성(官星·殺星) — 관인상생·살인상생**

자평진전은 인수격을 정·편으로 나누지 않으므로(「财与印不分偏正，同为一格而论之」, 논인수) 관·살의 쓰임도 정인격과 같다. 관은 인을 생하는 것만이 아니라 그 자체로 쓰고(「正官不独取其生印，而即可以为用，与用煞者不同」), 칠살은 부득이 쓰는 것이라 신중인경이나 신경인중일 때만 성격이다(「偏官本非美物，藉其生印，不得已而用之。故必身重印轻，或身轻印重，有所不足，始为有性」 — 茅状元·马参政). 겨울 木은 관을 보아도 귀하기 어렵다(「而冬木逢水，虽透官星，亦难必贵」, 논용신배기후득실) — 乙 일간 子월(子 본기 癸는 乙의 편인)도 같다.

```
살인상생 구조:
칠살(殺) →생→ 편인(偏印) →생→ 일간(我)
```

**② 재성(財星) — 재제편인(財制偏印)**

자평진전은 인을 정·편으로 나누지 않는다(「财与印不分偏正，同为一格而论之」, 논인수). 그래서 재성의 역할도 정인격과 같다 — 인이 가볍고 재가 무거우면 기신(재파인)이고, 인이 많아 신강하면 재로 덜어내는 용신이 된다(「印重身强，透财以抑太过」, 汪侍郎 〔辛酉 丙申 壬申 辛亥〕 — 申 본기 庚은 壬에게 편인이라 실은 편인격이다). 편인이 너무 강할 때 재성이 편인을 극(財克印)하여 균형을 잡는다.

### 기신

**① 식신으로 설수할 때의 재성**

식신 자체는 기신이 아니다 — 신강인왕이면 식상으로 설하는 것이 용신이다(「身印两旺，透食则贵，凡印格皆然」, 논용신배기후득실; 19번 §10). 이때 재성이 드러나면 재가 인을 깨 격이 무너진다 — 「印透食以泄气，而又遇财露」(논용신성패의 대기), 徐注 「又遇财露，则财损印为病，而破格矣」. 효신도식은 식신격의 일이다(§1).

**② 신강인중(身强印重)에 칠살**

「身强印重而透煞，印格败也」(논용신성패). 徐注: 「身强印重，须食神泄身之旺气，若不见食神而透煞，则煞生印，印又生身，皆为印格之忌也」. 식상이 함께 있어 살을 제하면 신왕인중이라도 귀격이다 — 「有用煞而兼带伤食者，则用煞而有制，生身而有泄，不论身旺印重，皆为贵格」(논인수).

**③ 편인 과다(偏印過多) — 후대 해석**

편인이 너무 많으면 일간이 나태하고 의존적이 되며, 편벽한 성질이 더욱 강해진다고 후대는 본다.

## 4. 성격(成格)

### 유형 ① 살인상생(殺印相生) — 인이나 일간에 모자람이 있을 때

원문은 칠살을 「不得已而用之」라 하고, 인이나 일간 한쪽이 가벼울 때만 쓴다 — 「故必身重印轻，或身轻印重，有所不足，始为有性…若身印并重而用七煞，非孤则贫矣」(논인수). 원전 명조 둘이 모두 편인격이다.

```
茅状元 〔己巳 癸酉 癸未 庚申〕 — 酉 본기 辛은 癸의 편인, 己土 칠살. 「此身轻印重也」
马参政 〔壬寅 戊申 壬辰 壬寅〕 — 申 본기 庚은 壬의 편인, 戊土 칠살. 「此身重印轻也」
己土·戊土 칠살이 인을 생하고(土生金) 인이 일간을 생함(金生水) → 살인상생
신강인중이면 같은 칠살이 패격이 된다(§3 기신 ②, §5 ②) — 식상이 함께 있어 살을 제하면 예외
```

徐注는 茅状元을 인이 너무 왕하고 재가 없어 「只能顺母之性，反以金水为吉」이라 하고, 马参政은 「以煞生印为用神，重在于印，不可见财」라 한다.

원전 실례(茅状元·马参政)는 문관이다 — 무관·문관을 구조만으로 단정하지 않는다.

### 유형 ② 재제편인(財制偏印)

```
예시: 편인이 강한 구조에서 재성이 편인을 적절히 극
      → 편인의 편벽함이 조절되어 격이 균형을 이룸
```

### 유형 ③ 식신 설수(泄秀) — 신강인왕

```
예시: 乙木 일간, 子월(癸水 편인), 천간에 丁火 식신 — 일간도 뿌리가 있어 신강인왕
      丁火가 왕한 乙木의 기운을 설하고, 겨울 木에 불이라 조후까지 겸함
      → 「身印两旺，透食则贵，凡印格皆然。而用之冬木，尤为秀气」(논용신배기후득실) → 성격
      재성이 드러나면 대기(帶忌)로 깨진다(§5)
```

## 5. 패격(敗格)

원문은 인격(정·편 공통)의 패격을 둘로 든다 — 「印轻逢财，或身强印重而透煞，印格败也」(논용신성패).

### 유형 ① 재파인(財破印) — 인이 가볍고 재가 무거움

「若印轻财重，又无劫财以救，则为贪财破印，贫贱之局也」(논인수). 편인이 약한데 재성이 강하게 투출해 인을 깨면 격이 무너진다.

### 유형 ② 신강인중에 칠살

살이 인을 돕고 인이 다시 일간을 도와 한쪽으로 쏠린다 — 徐注 「若不见食神而透煞，则煞生印，印又生身，皆为印格之忌也」. 논인수도 「若身印并重而用七煞，非孤则贫矣」라 한다. 다만 식상이 함께 있어 살을 제하고 신을 설하면 귀격이다 — 「有用煞而兼带伤食者，则用煞而有制，生身而有泄，不论身旺印重，皆为贵格」(논인수).

### 대기(帶忌) — 식신으로 설수하는데 재가 드러남

「印透食以泄气，而又遇财露」(논용신성패) — 徐注 「月令印绶，日元生旺，透食以泄身之秀，印格成也；又遇财露，则财损印为病，而破格矣」. 편인격이 식신으로 성격했다가 재성 때문에 깨지는 경우로, 식신격의 효신도식과 방향이 반대다.

---

## 6. 구격(救格)

원문의 구응: 「印逢财而劫财以解之，或合财而存印」(논용신성패).

### 유형 ① 비겁이 재를 막음

```
예시: 乙木 일간, 子월 癸水 편인 — 己土 편재가 투출해 癸水를 깨려 할 때
      다른 乙木 비견이 己土를 극(木克土) → 재 제어 → 인 보호 → 구격
```

### 유형 ② 재를 합해 인을 지킴(合財存印)

재성이 다른 글자와 합해 묶이면 인을 깨지 못한다.

## 7. 편인격의 특수 성질

**기예명(技藝命)**: 편인격은 정통 학문보다 기예·예술·종교·철학과 연결된다. 정인격이 정통 교육으로 관직에 오르는 형상이라면, 편인격은 특수한 재능으로 두각을 나타내는 형상이다.

**의식주 문제**: 식신격에 편인이 와서 식신을 빼앗으면(효신도식) 식신이 뜻하는 의식주·복록이 손상된다고 본다. 편인격에 식신이 투출한 것은 이 경우가 아니다(§1).

## 8. 정인격 vs 편인격 비교

| | 정인격 | 편인격 |
|---|---|---|
| 인성의 성질 | 따뜻하고 정통적 | 편벽하고 특수 |
| 재성 역할 | 인경재중이면 기신(재파인), 인다신강이면 용신 | 같다 — 「财与印不分偏正」 |
| 식신과의 관계 | 신강인왕이면 식신 설수가 상신(「身印两旺，透食则贵，凡印格皆然」) | 같다 — 편인격의 식신 투출도 효신도식이 아니다(「偏印透食…泄身之秀」) |
| 성격 키워드 | 학문, 명예, 정통 | 기예, 종교, 특수 재능 |
| 관·살과의 관계 | 관은 그 자체로 쓰고, 칠살은 신중인경·신경인중일 때만(茅状元·马参政). 겨울 木은 관을 보아도 귀하기 어렵다 | 같다 — 「财与印不分偏正」 |

## 9. 학파 간 이견

**이견 ①** 재성의 역할: 자평진전은 재의 역할을 정인격·편인격에서 같게 본다(「财与印不分偏正」 — 인경재중이면 재파인, 인다신강이면 재로 덜어냄). 후대 일부는 편인격에서 재제편인(財制偏印)을 따로 강조해 편인격의 재를 더 너그럽게 본다.

**이견 ②** 효신도식의 범위: 자평진전은 월령 식신에 편인이 온 것만 효신도식으로 보고, 월령 편인에 식신이 투출한 것은 설수로 본다(논용신). 후대 일부는 월령을 가리지 않고 편인과 식신이 만나면 효신도식이라 부른다 — 원문이 「不知月令而妄论」이라 한 읽기다.

## 10. 편인격 핵심 요약

핵심 특성: 인은 정·편을 나누지 않는다(「财与印不分偏正」). 효신도식은 식신격에 편인이 온 일이고, 편인격에 식신이 투출하면 설수다(「偏印透食…泄身之秀」)
성격: 관인상생(겨울 木은 예외), 인이나 일간이 가벼울 때 살인상생, 신강인왕에 식신 설수(재가 없어야), 인다신강에 재로 덜어냄(「印多逢财而财透根轻」)
패격: 인경재중(재파인), 신강인중에 칠살(식상이 함께 있어 살을 제하면 귀격 — 「有用煞而兼带伤食者」), 식신 설수에 재가 드러남(대기)
구격: 비겁이 재를 막음, 재를 합해 인을 지킴(「印逢财而劫财以解之，或合财而存印」)
