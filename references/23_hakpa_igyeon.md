# 학파별 이견 정리 — 자평진전파 vs 적천수파 vs 조후파

> 이 문서는 명리학 3대 학파(자평진전파·적천수파·조후파)가 서로 다른 견해를 보이는 주요 쟁점을 정리한 것이다.
> 사주 해석 시 학파 간 이견이 있는 항목을 만나면, 이 문서를 참조하여 양쪽(또는 세 쪽) 견해를 모두 제시한다.

---

## 학파 개요

```
자평진전파 (격국론 중심):
- 경전: 자평진전(子平眞詮), 심효첨(沈孝瞻) 저
- 핵심: 월령 기반 격국 판단 → 성격·패격·구격의 체계
- 방법론: 투출·통근 → 격국 결정 → 용신·기신 → 성패 판단
- 강점: 논리적·체계적, 재현 가능한 분석 프레임워크

적천수파 (강약론·종격론 중심):
- 경전: 적천수(滴天髓), 경도(京圖) 저 / 임철초(任鐵樵) 주석
- 핵심: 일간 강약 판단 → 억부(抑扶)·종격 판단
- 방법론: 일간의 세력 대비 → 신강이면 극설, 신약이면 생조
- 강점: 직관적, 종격·특수격 판단에 유리

조후파 (조후론 중심):
- 경전: 궁통보감(窮通寶鑑) / 난강망(欄江網)
- 핵심: 계절(월령)의 한난조습에 따른 조후 용신 결정
- 방법론: 일간 + 출생 월 → 필요한 오행(조후 용신) 결정
- 강점: 계절감에 충실, 실전 적중률이 높다는 경험론적 주장
```

## 이견 항목 1: 용신(用神) 결정의 최우선 기준

### 쟁점: 격국·억부·조후 중 무엇이 우선인가?

```
자평진전파:
- 격국 용신이 최우선
- "月令用神은 格을 이루는 핵심이며, 用神은 格에서 나온다"
- 억부론은 격국 안에서 보조적으로만 사용
- 조후는 격국·용신 결정 후 세부 보정 단계에서 참고

적천수파:
- 억부(抑扶) 용신이 최우선
- "일간의 강약을 먼저 판단하고, 강하면 극설하는 오행이 용신, 약하면 생조하는 오행이 용신"
- 격국은 일간 강약 판단 이후에 참고
- 종격 판단이 격국보다 앞선다

조후파:
- 조후 용신이 최우선
- "한겨울의 丙火에게는 무엇보다 따뜻함(木·火)이 필요하고, 한여름의 壬水에게는 시원함이 필요하다"
- 계절의 한난조습을 조절하는 오행이 곧 용신
- 격국·억부는 조후 용신을 보조

현대 강의 견해 (선운의 명리터, 후보 — 조후 위상 11편 이상, 용신 틀 간 서열 부정 7편 이상):
- 조후는 절대 용신이 아니라 생극·십성 아래의 한 요소다 (sMdvwstuIWI@8:47, DpaiovlGm7k@44:52) — 격국 우선·조후 보정이라는 자평진전파 순서와 같은 방향이다
- 한난조습은 길흉의 잣대가 아니다. 온도는 경쟁하며 일하는 강도, 습도는 환경의 편안함으로 읽는다 (aQDcL42uGNU@10:07, LmRqp2WaGUc@1:35:03)
- 조후가 없어도 나쁜 사주가 아니고, 조후가 지나치게 딱 맞으면 안주해 평균에 머무는 경우가 있으며 조후가 부족한 쪽이 정상에 서기도 한다 (DpaiovlGm7k@1:28:43, w4ol_a7fVs8@17:21) — 조후파의 조후=최우선 용신과 갈린다
- 격·억부·조후·병약 같은 용신 틀 사이에 서열을 매기지 않는다. 모든 글자가 영향력의 크기만 다르게 작용하고, 하나를 최고로 두면 그 틀에 갇히므로 질문(진로·편안함·돈)에 맞는 틀을 고른다 (fvbuC_S9oiU@1:18:57, qaFuxlppEqo@52:39, OrhNwIB9S1k@3:53)
- 신약이면 인비·신강이면 식재관이라는 공식도 경계하고, 길흉은 강약이 아니라 재관·식상의 움직임으로 본다 (yFUEDY2G22o@31:20)
- 선운 내부: 2018년 영상은 추위에 화·더위에 수·습에 금이라는 균형 처방 틀을 쓰고(sMdvwstuIWI), 2019년 이후에는 그런 기계적 처방이 틀렸다고 한다 (nObqAVG-SK4@1:25:32, poor 1편이라 참고용)

본 스킬의 입장:
→ 격국론 우선, 조후론으로 보정하는 병용 방식
→ 단, 종격 여부는 격국 판단 이전에 먼저 가린다 (적천수파 수용)
→ 조후 용신과 격국 용신이 일치하면 최상, 불일치하면 격국 우선
→ 선운 견해는 참고로 병기할 뿐 용신 판정·점수에 쓰지 않는다. 조후 용신이 원국에 없다는 이유만으로 흉으로 단정하려 할 때나 의뢰인이 용신 하나만 알려 달라고 할 때 반론·참고로 곁들인다 (37_sunwoon_layer.md)
```

## 이견 항목 2: 종격(從格) 성립 기준의 엄격성

### 쟁점: 미약한 통근이 있을 때 종격으로 볼 것인가?

```
적천수파 (음간은 관대, 양간은 엄격):
- 「五阳从气不从势，五阴从势无情义」(第01章 徐注의 적천수 인용)
- 음간: 통근이 1개 있어도, 그 통근이 충·합거·조토 위의 약한 근이면 종격으로 봄
- 양간: 약한 뿌리라도 있거나 인성이 통근하면 종하지 않음(「只要四柱略有根，或印有根，则弱归其弱，而不能从」)
- "뿌리가 있어도 기능하지 못하면 없는 것과 같다"
- 가종(假從)이라는 중간 개념을 활발히 사용
- 종격의 비율을 상대적으로 높게 봄

자평진전파 (엄격한 기준):
- 통근이 1개라도 살아 있으면 종격이 아니라 극약 일반격
- "뿌리가 있으면 일간은 무너지지 않는다"
- 종격의 비율을 매우 낮게 봄 (전체 사주의 5% 이하)
- 가종 개념을 인정하지 않거나 회의적

조후파:
- 종격 판단에 대해 독자적 기준이 뚜렷하지 않음
- 주로 적천수파나 자평진전파의 기준을 차용
- 조후적으로 볼 때, 종격이든 일반격이든 계절 조절이 중요하다는 입장

현대 강의 견해 (선운의 명리터, 가설 — 3편, 대표 2편):
- 진종은 거의 없고 가종이 흔하다. 신약 종격도 모두 가종이다 (nVmeXqlkdVE@11:30, KI8EN4XEbf4@13:11). 자평진전파의 낮은 종격 비율과 적천수파의 가종 개념을 절충한 위치다
- 가설(1편): 종하는 오행이 득령하는 계절에 났을 때만 종격이 선다 (dvYivd3UyqE@18:12) — 21 §3-2 ④에는 이 조건이 없다

실전 처리 원칙:
→ 미약한 통근이 있는 경계 사례에서는 양쪽 견해를 모두 제시
→ 대운의 실제 흐름으로 검증 가능: 인성·비겁 대운에서의 길흉이 판별 기준
→ 21 Step 5의 진종 확정은 유지하되 진종으로 보기 전에 가종 가능성을 병기한다. 선운 견해는 참고로 병기할 뿐 종격 판정에 쓰지 않는다
```

## 이견 항목 3: 양인격(羊刃格)의 독립 격국 인정 여부

### 쟁점: 양인을 독립된 격국으로 볼 것인가?

```
자평진전파:
- 양인격을 독립 격국으로 인정
- "양인용살·양인용관" — 양인은 관살로 제어해야 성격(「刃宜伏制，官煞皆宜」, 논양인)
- 양인격의 용신: 관살. 재·인은 관살을 도와 반긴다(「财印相随，尤为贵显」, 「阳刃用之，则赖以制刃…故反喜财印，忌制伏也」)
- 양인격의 기신: 관살을 치는 식상(「阳刃透官煞而露财印，不见伤官，阳刃格成也」). 관살이 없으면 败(「阳刃无官煞，刃格败也」)
- 양인이 칠살과 합하면 제어하는 공이 없다(「刃能合煞，则有何功」) — 12번 §7

적천수파:
- 양인을 독립 격국으로 보지 않음
- 양인은 신살(神煞)의 일종이며, 일간이 극강한 상태의 지표일 뿐
- 일간이 강하면 식상·재성·관살로 억부 → 별도의 양인격 불필요

조후파:
- 양인격에 대해 별도 논의 없음
- 양인이 있는 사주도 조후 용신 결정에는 영향 없음

실전 처리 원칙:
→ 양인이 월지에 있는 사주에서 자평진전파의 양인격론을 기본으로 제시
→ 적천수파의 견해(독립 격국 부인)도 함께 언급
→ 양인의 실전 영향력은 학파를 불문하고 인정 (과격·사고·수술의 상)
```

## 이견 항목 4: 격국론에서 억부론의 위치

### 쟁점: 신강·신약(억부론)을 격국 판단에 어떻게 반영하는가?

```
자평진전파:
- 격국론이 주(主), 억부론은 종(從)
- 格의 성패를 먼저 보고, 格 안에서 신강·신약을 보조적으로 고려
- "신약하다고 무조건 인성이 용신인 것은 아니다 — 格이 요구하는 용신이 다를 수 있다"
- 예) 식신격 신약: 인성은 식신을 쳐 꺼리고(「食神虽逢正印，亦谓夺食」) 비겁으로 돕는다(「财食重则喜帮身」, 논식신취운) (格의 논리)
- 반대로 재격 신약은 인을 찬다(「有财格佩印者，盖孤财不贵，佩印帮身」, 논재). 식신생재는 신강일 때만이다(「有财用食生者，身强而不露官」)

적천수파:
- 억부론이 주(主), 격국론은 참고
- 일간의 강약을 먼저 판단하고, 강약에 따라 용신을 결정
- "신약하면 인성·비겁, 신강하면 식상·재성·관살"이 기본 공식
- 격국은 억부 판단 이후 해석의 풍부함을 위해 참고

조후파:
- 억부론과 조후론을 병용
- 신강·신약 판단 후, 조후로 최종 용신을 확정
- "신약해도 조후가 더 급하면 조후 용신을 우선한다"

현대 강의 견해 (선운의 명리터, 후보 — 17편 이상):
- 강약은 우열이나 길흉의 근거가 아니라 주도권을 쥐는 방식의 차이다. 신강은 자기중심, 신약은 상대에 맞춤이며 해석에서 차지하는 비중도 10~20% 정도로 작은 입문용 참고다 (sMdvwstuIWI@0:02, T82DTxLcLlk@1:37, vcl9VXK7Gd8@1:14)
- 판단 순서는 구조→상생→강약이고, 판정은 인성·비겁 개수 등으로 단순하게 하며 경계 사례는 억지로 가르지 않는다. 정보량은 통변 층에서 쓴다 (DYA2QHL5oP0@17:14, v9-P61IO2gY@15:33)
- 자평진전파(격국 주)와 같은 방향이고 억부 우선(적천수파)과는 어긋난다
- 선운 내부: 비중(20% 이하)과 판정 순서(월지→지지→나머지, 3d6TY_Shkmo)가 영상마다 갈린다

이견의 핵심:
→ 자평진전파: 格이 먼저, 신강·신약은 格 안에서
→ 적천수파: 신강·신약이 먼저, 格은 이후
→ 이 차이 때문에 같은 사주에서 용신이 달라질 수 있음
→ 억부 우선의 풀이를 내거나 비율이 애매한 경계 사례를 다룰 때 강약은 길흉 자체의 근거가 아니라는 견해를 참고로 부기한다. 선운 견해는 판정·점수에 쓰지 않으며 강약 판정이 격국·용신을 뒤집게 하지 않는다 (37_sunwoon_layer.md)
```

## 이견 항목 5: 조토(燥土)와 습토(濕土)의 오행 기능 차이

### 쟁점: 未·戌(조토)과 丑·辰(습토)을 같은 土로 볼 것인가?

```
적천수파 (구분 중시):
- 조토와 습토는 같은 土지만 기능이 전혀 다름
- "조토불생금(燥土不生金)" — 未·戌의 건조한 흙은 金을 생하지 못함
- "습토불극수(濕土不克水)" — 丑·辰의 축축한 흙은 水를 제대로 극하지 못함
- 통근 판단에서도 조토·습토를 구분: 조토 위의 金은 약한 근

자평진전파 (상대적으로 덜 구분):
- 土는 土: 장간의 본기가 중요하지 조토·습토 구분은 부차적
- 未의 본기는 己土, 戌의 본기는 戊土 → 장간으로 판단하면 됨
- 계절에 따른 오행 기능 변화를 인정하지만, 이것을 격국 판단의 핵심으로 삼지는 않음

조후파 (강하게 구분):
- 조후론의 핵심이 한난조습이므로, 조토·습토 구분은 필수
- 여름 사주에서 조토가 많으면 → 조열함 가중 → 水가 더 급히 필요
- 겨울 사주에서 습토가 많으면 → 한습함 가중 → 火가 더 급히 필요

현대 강의 견해 (선운의 명리터, 후보 — 7편 이상, 생금 쟁점은 지지 쪽 영상과 합산):
- 습토(辰·丑)는 생금하고 조토(未·戌)는 못 한다는 통설을 반박한다. 土는 계절 사이의 전환을 매개하는 자리라 방향이 정해진다: 未=여름→가을(화생토·토생금, 진짜 생금), 辰=봄→여름(목생화), 戌=가을→겨울(금생수), 丑=겨울→봄(수생목) (JaNnXxdzhio@6:59, TWrslVbuTcQ@27:34, FG-v59vPAr4@6:53)
- 토생금에는 적당한 습이 필요한데 辰은 과습, 戌은 메마름이라 생금이 안 되고 未가 알맞다. 辰戌丑 토는 경금을 생하지 못해 재생관이 형태만 남는다 (Ud0l9r82Ye0@1:10, Bihoyd4_KcA@3:06)
- 2025년에는 같은 결론을 오행 귀속으로 표현한다: 戌은 금, 辰은 목으로 셈하고 생금하는 토는 무·기·미토로 한정한다 (FG-v59vPAr4@6:53, RwjVwfoElC4@7:37)
- 천간에서는 무토가 금을 기르고 기토는 유보한다 (JaNnXxdzhio@15:33)
- 겨울(해·자·축)은 냉(冷)일 뿐 습하지 않다. 한습은 성립하지 않는 말이고 丑을 습토로 부르는 관행도 비판한다 (NWNd6rAUXek@19:50, jNj3rNR0N98@20:54)
- 접점: 07 진월 경금 원문도 월령 무토가 사령한 辰월에는 금을 생할 이치가 없다고 한다. 단 이것은 월령 사령 토의 이야기라 辰 일반의 속성과는 구분된다
- 선운 내부: 未만 진짜 생금이라는 방향은 2019년 영상과 2025년 영상에 모두 보인다
```

## 이견 항목 6: 상관견관(傷官見官)의 해석

### 쟁점: 상관이 정관을 만나면 반드시 흉한가?

```
자평진전파:
- "상관견관 위화백단(傷官見官 爲禍百端)" — 상관이 관을 보면 화가 백가지
- 단 금수상관은 예외: 「伤官见官，为祸百端，而金水见之，反为秀气…调候为急」(논용신배기후득실). 败 조건도 「伤官非金水而见官」(논용신성패구응)이고, 금수상관은 관을 용신으로 쓴다(「有伤官用官者，他格不用，金水独宜，然要财印为辅，不可伤官并透」, 논상관)
- 그 밖의 상관격에서 정관은 기신: 상관이 관을 극하면 패격
- 구응: 인이 상관을 제어하거나(「官逢伤而透印以解之」), 재가 상관을 받아 관을 생하면(「伤官生财来生官，反可以解」) 풀린다

적천수파:
- 상관견관을 절대적 흉으로 보지 않음
- 일간이 신강하고 관성이 약할 때, 상관이 관을 극하는 것은 오히려 밸런스
- 일간의 강약에 따라 상관견관의 길흉이 달라진다는 입장
- "신강한 사주에서 상관견관은 기운의 흐름이 원활한 것"

조후파:
- 상관견관 자체보다 조후 균형이 중요
- 상관과 관의 오행이 조후적으로 필요한 오행이면 흉하지 않을 수 있음

현대 강의 견해 (선운의 명리터, 후보 — 후기 입장):
- 상관견관을 흉으로 단정하지 않고 부조리를 교정하는 행동 양식·개혁의 자극제로 읽는다 (Pmh3yhwyP2U@9:41). 구응(재생관·관생인 중 하나)만 성립해도 큰 능력이 된다고 본다 (K04BSZhNRso@1:07:36)
- 인성이 있으면 잘못된 관을 바로잡는 공, 인성이 없으면 멀쩡한 관을 친 흠이라는 구응 기준은 자평진전과 같은 방향이다 (Fv6nO3uYAuo@20:44). 정인·편인에 따른 제화의 차이는 항목 21을 본다
- 선운 내부: 2025년 일부 강의는 권위 부정으로 화를 부른다는 쪽으로 다시 기운다 — 입장이 고정되어 있지 않다

실전 처리 원칙:
→ 기본적으로 자평진전파의 "상관견관 흉"을 원칙으로 삼되, 금수상관(겨울 金일간의 상관격)은 관을 반긴다 (자평진전 원문)
→ 단, 일간 강약과 전체 구조를 고려하여 적천수파의 견해도 부기
→ 인성이 상관을 제어하거나 재가 상관을 받아 관을 생하면 구격으로 판단
→ 상관견관이 반드시 나쁜가를 묻는 질문에 후기 강의 견해를 참고로 병기하되, 기본(원칙상 파격, 구응으로 풂, 금수상관 예외)을 바꾸지 않고 판정·점수에 쓰지 않는다 (37_sunwoon_layer.md)
```

## 이견 항목 7: 합충형파해의 실전 비중

### 쟁점: 형(刑)·파(破)·해(害)를 얼마나 중시할 것인가?

```
전통 명리파 (연해자평 계열):
- 합충형파해를 모두 동등하게 중시
- 특히 형(刑)은 관재·형벌의 핵심 지표
- 삼형이 있으면 반드시 법률 문제가 있다고 봄

적천수파:
- 충(沖)을 가장 중시, 형은 그 다음
- 파·해는 비중이 낮음
- "충은 실제 사건, 형은 갈등의 방향, 파·해는 미세한 불화"

자평진전파:
- 합(合)·충(沖)·형(刑)을 격국 성패에 직접 반영 — 월령 용신을 형·충하면 破格(「刑冲俱不为美，而刑冲用神，尤为破格」, 논형충회합해법), 정관격 败 「官逢伤克刑冲」
- 회합이 형·충을 풀기도 하고(「会合可以解刑」) 형·충이 회합을 풀기도 한다(徐注 「刑冲亦可以解会合」) — 자리와 세력으로 정한다
- 파·해는 격국 분석에 큰 영향을 주지 않으므로 비중 낮음

현대 실전파:
- 합 > 충 > 형 순으로 비중
- 파·해는 거의 무시하거나 참고 수준
- 삼형은 건강·관재와 관련하여 부분적으로 인정

현대 강의 견해 (선운의 명리터, 후보 — 형·파·해 불사용 5편 이상, 합 우위 독법은 가설):
- 근거가 분명한 것은 삼합·방합·천간합뿐이고, 원리가 불분명한 형·파·해는 쓰지 않는다 (rClqfAW1FLA@31:22, UZWjXF89fag@32:54, NmrwatMrpns@3:47)
- 형을 흉 단정 대신 생활 심리로 옮긴다: 인사형=목생화의 성장, 자묘형=왕지끼리 긴장, 자형=급발진 (Rw2nQ2IbHQY@2:07, NmrwatMrpns@20:19, pyQJRHy3eKU@1:37:44)
- 합 > 충 > 형 순 비중에 가깝고, 실제 사고는 충보다 합에서 더 난다는 독법까지 있다 (가설 1편, 8TBGdvh4pNY@13:40)

실전 처리 원칙:
→ 합·충·형을 핵심으로 분석 — 월령 용신을 형·충하면 격 성패에 반영 (자평진전)
→ 형의 관재·건강 해석은 참고
→ 파·해는 인간관계 갈등의 보조 지표로만 언급
→ 삼형의 관재·건강 해석은 22 §4-2대로 참고로 두고, 형을 단정 서술할 때 선운식 생활 심리 번역을 병기한다. 파·해가 보조라는 점은 선운 견해와 가깝다. 선운 견해는 판정·점수에 쓰지 않는다 (37_sunwoon_layer.md)
```

## 이견 항목 11: 월지 육합의 격국 변화 여부

### 쟁점: 월지가 육합으로 합화되면 격국이 바뀌는가?

```
격국 변화 인정파 (일부 자평진전 해석자):
- 월지가 육합하여 합화가 성립하면, 월지의 오행이 변함
- 오행이 변하면 격국도 변함
- 예) 月子 + 日丑 → 子丑합土 → 월지가 土로 변하면 격국 재결정

격국 변화 부인파 (주류):
- 월지는 格의 근거지이므로 합으로 쉽게 변하지 않음
- 육합이 있어도 월지의 본기(本氣)는 유지됨
- 合化가 완벽히 성립하는 경우에만 격국 변화 고려 (극히 드뭄)

적천수파:
- 합화의 성립 조건을 엄격히 적용
- 월령의 지지를 받아야 합화 → 월지 자체가 합하는 경우 합화 판단이 복잡
- "월지의 합은 격국을 흔들 수 있지만, 합화까지 가야 격국이 변한다"

현대 강의 견해 (선운의 명리터, 후보 — 합화 부정 11편 이상, 항목 13 참조):
- 합화를 부정하므로 월지 육합도 월지의 본기를 바꾸지 않는다(부인파와 같은 방향). 월지가 합에 걸려도 기능은 상당 부분 남는다 (LI9awLcNu5k@5:22, aqG_z6Xri7E@7:19)
- 소수 조건부(가설): 월지가 왕지일 때만 그 오행이 강해진다 (9vaDOHdzFfI@42:23) — 적천수파의 월령 조건과 닿는다

실전 처리 원칙:
→ 월지 육합은 격국을 쉽게 변화시키지 않는다 (부인파 기본)
→ 단, 합화 조건이 완벽히 갖춰지면 격국 변화 가능성을 제시
→ 대운·세운에서 월지 합이 발생하면 → 격국의 근거 동요로 해석
→ 부인파 기본을 유지한다. 선운 견해는 참고로 병기할 뿐 격국 판정·점수에 쓰지 않는다 (37_sunwoon_layer.md)
```

## 이견 항목 12: 육합 합화 결과 오행의 논쟁

### 쟁점: 卯戌합은 火인가? 午未합은 火인가 土인가?

```
卯戌합:
- 합화 火설 (주류): 卯戌합의 결과 오행은 火
- 합화 불성립설 (일부): 卯(木)와 戌(土)의 합은 합거일 뿐 합화되지 않음
- 적천수파: 합화가 되려면 월령이 火(巳午)여야 함

午未합:
- 합화 火설: 午(火) + 未(土지만 丁火 장간) → 火로 합화
- 합화 土설: 午의 己土 장간 + 未의 己土 본기 → 土로 합화
- 학파마다 견해가 갈리며 통일되지 않음

현대 강의 견해 (선운의 명리터, 후보 — 합화 부정 11편 이상, 항목 13 참조):
- 육합 전체에서 합화를 부정한다. 巳申합이 수가 된다는 통설은 근거 없는 풀이라 하고(BWvU2dGNxi4@11:30, good, 2026-05), 합화 불성립설을 넘어 합거마저 부인하며 원래 글자는 그대로 작용한다고 본다 (6afRAEDZjr0@1:58:04, 3pNgTsbJwRw@43:24)
- 선운 내부: 子丑합이 수가 된다는 발언도 있어 합화 오행 서술이 일정하지 않다 (NMT5yxBY3vU@9:47)

실전 처리 원칙:
→ 육합의 합화 결과가 논쟁적인 경우, 합거(合去)로만 판단
→ 합화 오행이 명확한 것(子丑→土, 寅亥→木, 辰酉→金, 巳申→水)만 합화 적용
→ 卯戌·午未의 합화 오행은 학파 이견이 있음을 명시
→ 합거로만 판단하는 기존 원칙 위에 합거마저 약하게 보는 견해가 있다고 부기한다. 선운 견해는 참고로 병기할 뿐 판정·점수에 쓰지 않는다 (37_sunwoon_layer.md)
```

## 이견 항목 13: 합(合)의 결과 — 합거·합화인가, 기능 유지인가

### 쟁점: 천간합·지지합이 성립하면 글자가 기능을 잃는가, 오행이 변하는가, 기능이 남은 채 지향만 달라지는가? (항목 11·12는 육합의 월지·합화 오행만 다룬다)

```
합거 기본설 (22 §1-2 ①, 21 §1-4 허근 목록):
- 합한 두 글자가 본래 기능을 잃는 것이 가장 흔한 결과. 용신이 합거되면 흉, 기신이 합거되면 길

합화 성립설 (22 §1-1·§2-1·§2-2 ①):
- 월령이 화신 오행을 받칠 때만 합화가 성립한다 (예: 丙辛은 월령 亥子). 실전에서 합화는 드물다

합이불화설 (22 §1-2 ③):
- 끌림은 있으나 오행은 바뀌지 않고 기능이 약해지는 정도

궁통보감 원문 (달에 따라 합화를 쓰거나 꺼린다):
- 정화 일간 정월: 임수를 만나 정임합목이 되면 약한 가운데 살아나 대귀 (경금이 깨지 않아야 함, 04)
- 무토 일간 술월: 「却忌化合」 — 무계합화되면 계수의 윤토 기능을 잃는다 (05)

현대 강의 견해 (선운의 명리터, 후보 — 합화 부정 11편 이상, 합거 부정 8편 이상):
- 합화는 없다. 합해도 글자의 성질이 남고 쓰임·방법·시차(지향)만 달라진다 (45jloW_Nnmk@1:24:45, aqG_z6Xri7E@7:19, kKASfWFS7TU@24:59)
- 합거도 아니다. 합해도 기능의 상당 부분이 남고, 합이면 못 쓴다는 기계적 판단을 버린다 (LI9awLcNu5k@5:22, pyQJRHy3eKU@1:11:16, Y0ROwMppHcs@50:30)
- 이유로 합화를 인정하면 운마다 격과 강약이 뒤집혀 해석이 불가능해진다는 점을 든다 (aqG_z6Xri7E@9:25)
- 합을 성립 판정 대신 사건·심리 유형으로 읽는다 (가설 수준의 서술): 정임합은 저력·집착·묶임, 무계합은 원만해지고 나눌 의무가 생기거나 일정이 지연, 병신합은 신분 상승이 부르는 소탐대실, 갑기합은 상대가 보내는 관심 (LI9awLcNu5k@24:08, ZVrkP9m42WM@41:04, I5NOsPShrf8@26:58)
- 소수 조건부 (가설): 월지가 왕지일 때만 그 오행이 강해진다 (9vaDOHdzFfI@42:23, 9DrunLd_uyw@1:40:31)
- 삼합·방합·천간합만 근거가 분명하다고 보고, 합이 많으면 해결이 미뤄져 사고가 충보다 합에서 더 난다는 독법이 있다 (가설 1편, 8TBGdvh4pNY@13:40)
- 선운 내부: 2014년 정임합 서술(uAorz8JTFNI@6:01)에는 합화 논의가 없고, 합화 불인정은 2019년 이후 점점 분명해진다. 합이 걸린 글자의 무게도 영상마다 다르다 — 일시적 소홀 정도라는 말(pyQJRHy3eKU@1:11:16)과 일간이 합되면 그것만 바라본다는 말(6nK1P3Nttx4@2:15:16)이 갈리고, 무계합은 원만해진다는 서술과 지연된다는 서술이 같은 해에 공존한다. 육합 합화 오행도 불변(6afRAEDZjr0@1:07:36)과 子丑합이 수가 된다는 발언(NMT5yxBY3vU@9:47)이 엇갈린다

실전 처리 원칙:
→ 합거·합화·합이불화 판정은 22 §1-2 기준을 그대로 쓴다 (합거 기본, 합화는 월령 조건이 갖춰질 때만). 합화 조건이 모자라면 합이불화로 보수적으로 처리하는 것이 선운 견해와도 방향이 가깝다
→ 합거로 용신이 약해진다고 판정한 자리에서는 "합해도 기능이 남는다고 보는 견해가 있다"를 한 줄 병기한다. 합 때문에 불안해하는 질문에는 사건 유형 서술(37_sunwoon_layer.md)을 참고로 곁들인다
→ 선운 견해는 참고로 병기할 뿐 합거·합화 판정과 용신·기신 결정, 강약 판정에 쓰지 않는다. 합 사고 우위나 월지 왕지 조건 같은 가설은 서술에도 단정해서 싣지 않는다
→ 합의 거리 제한이 없다거나 쟁합이 오히려 편하다는 단독 서술(각 1편)은 참고로도 싣지 않는다
→ 육합 합화 오행(子丑·卯戌·午未)은 항목 11·12를 따르며 선운 한 편의 발언으로 정하지 않는다. 28 ③합충축 점수는 변경하지 않는다
```

## 이견 항목 14: 충(沖)의 성격 — 파괴인가, 만남인가

### 쟁점: 천간충·지지충을 서로의 기능을 깨는 관계로 읽는가, 이질적인 것이 만나 방향이 갈리는 계기로 읽는가? 무엇이 결과를 가르는가?

```
저장소 기본 (22 §3-2, §7, 09):
- 정면 대립해 서로의 기능을 파괴한다. 월령을 받은 쪽이 이긴다 (왕충쇠·쇠충왕·균등충)
- 용신 통근처가 충당하면 흉, 기신 통근처가 충당하면 길, 월지 충당은 격국의 근거 동요 (「刑冲用神，尤为破格」, 논형충회합해법)
- 합이 충을 풀기도 하고 충이 합을 풀기도 한다 (22 §7 ①②)
- 천간충: 충당한 천간은 기능이 흔들리고 지지에 뿌리 있는 쪽이 버틴다. 병임충은 충이면서 조화로 읽히는 긴장이 있다 (09). 乙辛충은 신금이 을목을 직접 극하는 편관 관계다 (02)
- 사고지끼리의 충은 충극이 아니라 충동 (35 §4 — 자평진전 「四墓土自为冲」)

적천수파 (항목 7):
- 충을 가장 중시하고 실제 사건으로 본다

현대 강의 견해 (선운의 명리터, 후보 — 충 하나로 단정하는 풀이 비판 31편, 만남·방향 전환 읽기 14편(그중 6편은 poor), 결과를 가르는 요인 16편):
- 글자 하나의 충·형으로 길흉을 단정하는 것은 공포 조장이다. 충이 와도 일이 없는 경우가 훨씬 많고, 일지 충만으로 힘들다고 결론 내는 것은 과정 없는 해석이다 (uQQYz9HJyrU@3:44, ixZG25EbkEg@1:36:53, JOt0j0u91jA@35:14)
- 충은 파괴가 아니라 서로 겨뤄 위치를 확인하는 만남이고 결과는 좋음·나쁨·무사 중 하나다. 후기에는 천간충=방향·속도, 지지충=생활 루틴의 변화로 나눈다 (MlERAS2M5w8@2:11, 9DrunLd_uyw@1:18:45, NmrwatMrpns@1:05)
- 결과는 원국의 상생 구조, 천간·지지 층위, 대운·세운의 무게에 따라 갈린다 (UnuxLJWCzxs@48:36, TONbAlAPBXU@15:32)
- 천간충의 모양: 乙辛충은 급격한 끌림·결합 또는 빼앗김이고 목적·기한이 있는 단기 몰입, 원국에 화가 있으면 풀린다. 丙壬충은 흉이 아니라 도약 추진력·속도 상승. 丁癸충은 죽음이 아니라 혈류가 막히는 정지 신호, 무거운 책임을 맡는 작용 (Pvf7fIIi8mE@10:55, TF-YnHHrGCA@28:32, 8-r6WvKa2AI@23:10)
- 가설(fair 2편 + poor 1편): 충하는 두 오행 사이를 잇는 오행이 원국에 있으면 협력, 없으면 싸움 — 금목충엔 화, 수화충엔 토 (UnuxLJWCzxs@48:36, TONbAlAPBXU@15:32, rahzcbWC3Ck@21:11). 토가 있어도 정계충을 못 막는다는 반례 발언이 있다 (vFy7jLNv4cA@19:10)
- 가설(2편): 진술충으로 창고가 열린다는 풀이는 의미가 없고, 지장간은 충해도 움직이지 않는다 (6gfvc_Rg7eQ@45:18, BWvU2dGNxi4@24:38) — 35 §4와 같은 방향
- 지지충에 장기·사건을 직결하는 라벨과 막연한 건강 주의는 상담이 아니라고 본다
- 선운 내부: 초기(2014~2021) 독법에는 을신충=빼앗김, 축미충=승진 같은 다른 상이 있고, 충을 한계를 마주하는 검증으로, 합을 방심의 온상으로 읽기도 했다 (8TBGdvh4pNY@13:40). 乙辛충은 2015년 흉·속박(buV9JfSbcRk@19:47)에서 2021년 이후 결합으로, 丙壬충은 2015년 작은 일이 커진다에서 2022년 이후 중립으로 옮겨 갔다

실전 처리 원칙:
→ 충의 판정(왕충쇠·쇠충왕·월령 기준, 통근처 충당, 월지 충당의 격 영향)은 22 §3-2대로 하며, 용신이 충당하면 흉이라는 기준을 유지한다
→ 선운 견해는 참고로 병기할 뿐 판정·점수에 쓰지 않는다. 서술할 때 "무엇이 깨진다"보다 "무엇이 맞부딪혀 방향이 갈린다"를 먼저 말하고 22 판정 결과를 이어 붙인다 (31 §6 단정 금지와 같은 방향)
→ 22 §3-1 영향 열은 참고 라벨로만 쓰고 장기·사건을 단정하지 않는다. 의뢰인이 충 하나로 불안을 호소하거나 충의 길흉을 물을 때 선운 견해를 곁들인다 (구체 모양은 37_sunwoon_layer.md)
→ 통관 오행 규칙과 乙辛충의 화 조건은 가설이라 판정에 쓰지 않는다. 사고지 충개고는 35 §4(충으로 격을 세우지 않음)와 32 §4-2(서술 층위 개폐)의 구분을 유지한다. 28 ③ 점수는 변경하지 않는다
```

## 이견 항목 15: 편중·중화 — 병(病)인가, 특화인가

### 쟁점: 한 오행·십성이 쏠린 사주는 고쳐야 할 병인가, 그 방향으로 특화된 상태인가? 균형(중화)이 최선인가?

```
적천수 계열 (21 §2 Step 4, 25의 저장소 기본 틀):
- 인비 대 극설 비율 4:4 전후의 중화를 가장 좋은 균형으로 본다
- 극단적 편중은 병(病)이며 제어 오행이 약(藥)이다 (25: 지지 3자·8자 중 5자·설기량 2배 기준). 편중이 극단적이면 격 공식을 멈추고 병약론으로 병을 진단해 약을 용신으로 삼는다

자평진전파:
- 균형 자체를 목표로 삼지 않고 격의 성패와 구응(19)을 기준으로 본다

현대 강의 견해 (선운의 명리터, 후보 — 편중 특화 11편 이상, 중화 부정 8편 이상):

- 중화·오행 구비는 평범한 경우가 많다. 균형은 상생이 받쳐 줄 때만 의미가 있고, 상생이 이끌지 않는 강약은 뜻이 적다. 토를 중앙이라 중화라 하는 것은 말장난이라고 본다 (rClqfAW1FLA@36:46, ApETSSWjlO0@6:05, DYA2QHL5oP0@2:09)

- 가설(2편): 편중 사주는 운에 덜 흔들린다
- 선운 내부: 2019년에는 적당히 탁한 사주가 세상에 적응한다고 보았고(kpzteifxQ4I), 2020-03·2023-10에는 중화를 긍정하는 영상이 있다 (T82DTxLcLlk@9:48, 3gUU2GqgZJk@13:23). 2022년에는 완전한 중화는 없으면서 적당한 신약을 안정의 기준으로 말했고(wH5tZWsdY-s), 2020-05 이후 다수와 2024~2025년은 중화 부정이다

실전 처리 원칙:
→ 판정은 25의 적용 기준(3종)과 21 Step 4의 4:4 개수 비율 분류를 그대로 쓴다. 기준을 채우면 병약 진단, 못 채우면 격 공식. 저장소 기본 입장은 바꾸지 않는다
→ 병으로 진단한 경우에도 "병으로 보는 쪽 / 특화로 보는 쪽" 두 견해를 병기하고 쏠림이 상생으로 이어지는지를 함께 본다. 가장 좋은 균형이라는 평가는 단정하지 않는다
→ 선운 견해를 꺼내는 경우: ① 의뢰인이 오행이 안 갖춰져서 불리한지 물을 때 ② 병약 진단의 어조를 교정에서 특화 방향의 부작용 관리로 옮길 때 ③ 오행 구비=평탄이라는 속설을 반박할 때. 참고로 병기할 뿐 판정·점수에 쓰지 않는다 (37_sunwoon_layer.md)
→ 중화 긍정 영상이 섞여 있어 하나의 정설로 소개하지 않는다. 쏠림을 결함으로 받아들이는 의뢰인에게는 대운의 실제 흐름으로 어느 견해가 맞는지 검증하도록 안내한다
```

## 이견 항목 16: 쟁재(爭財)·겁재탈재의 해석

## 이견 항목 17: 재성생살(재생살)과 칠살 처리의 기준

### 쟁점: 재가 칠살을 생하는 구조는 원칙상 기신인가, 신강하면 권위·전문성이 되는 구조인가? 칠살을 가르는 1순위 기준은 식신제살인가 재생살인가?

```
자평진전파 (12):
- 칠살격 재성생살은 원칙상 기신 (「七煞逢财无制，七煞格败也」), 식신제살이 최상 (「煞用食制者，上也」)
- 예외를 원문이 스스로 든다: 재가 인을 제거해 식신을 살리는 경우(周丞相), 신중살경에 재로 격을 맑히는 경우(刘运使), 徐注 신강살약의 재자살

현대 강의 견해 (선운의 명리터, 후보 — 4편 이상):
- 재생살이면 편관이 권위·실력·책임으로 쓰이고, 재가 없거나 약하면 살이 일간을 직접 친다 (bN1crHPy_5c@16:31, ixZG25EbkEg@50:31, 4TMEkxheeBA@1:07:43)

- 재생관은 절차를 밟아 한 걸음씩, 재생살은 꾸준히 하다 임계점에서 터지는 성공이다 (cikcaMjdGl8@9:49)
- 약(poor 1편): 재생살은 일간이 살을 버틸 만큼 신강해야 성립한다 (tt0rNq0Bo-Y@54:00)

실전 처리 원칙:
→ 칠살격 판정은 자평진전 기준(제어 우선, 재성생살 원칙상 기신 + 원문 예외)을 기본으로 제시한다

→ 직업·처세 서술에서만 권위·전문성으로 쓰는 쪽을 참고로 제시하고, 선운 견해는 판정·점수에 쓰지 않으며 격의 성패 판정을 뒤집지 않는다 (37_sunwoon_layer.md)
```

## 이견 항목 18: 정재·편재의 성정 구분

### 쟁점: 편재를 유동·사업·투기의 큰 재물, 정재를 성실·안정의 작은 재물로 읽는 후대 풀이를 어디까지 받을 것인가?

```

- 편재=아버지는 원문이 직접 설명한다 (16 §7 이견②)

현대 강의 견해 (선운의 명리터, 후보 — 5편 이상):
- 정재=작은 돈·편재=큰 돈, 정재=월급·편재=사업이라는 구분은 틀렸다. 재는 현실을 뜻하며 정재는 현재, 편재는 미래 개념이다 (ZgJw3H1SREQ@11:41)

- 직업 형태는 정재=소속·정해진 일, 편재=독립·여러 일이다 (LLVaYY3bMjs@10:53)
- 선운 내부: 2020-08에는 편재를 쓰려고 벌며 일을 키우는 쪽으로 말해 이동이 있다 (xUV0fH2Gy_A@18:06)

→ 격 판정은 정·편을 구분하지 않는 자평진전 기준으로 한다
→ 성정 서술이 필요할 때 후대 풀이(유동·사업)와 선운 견해(독립·이상) 두 갈래가 있음을 같이 보여 주되, 선운 견해는 참고로 병기할 뿐 격의 성패·점수에 쓰지 않는다 (37_sunwoon_layer.md)
→ 편재를 곧 사업가로 단정하는 문장은 쓰지 않는다
```

## 이견 항목 19: 식상생재는 사업가의 명인가, 노동·기술로 버는 구조인가

## 이견 항목 20: 도식(효신도식)의 길흉과 범위

### 쟁점: 편인이 식신을 극하는 도식을 식신격의 최대 기신으로만 읽는가, 길흉 단정 없이 쉼·몰입의 구조로 읽는가? 어느 격에서 도식이라 부르는가?

```
자평진전파 (14·17):
- 월령 식신일 때 인(정·편 공통)이 식신을 극하면 탈식·효신도식이며 식신격에서 가장 치명적인 기신 (여름 木은 예외)

- 후대 일부는 월령을 가리지 않고 편인과 식신이 만나면 도식이라 부른다 (원문이 월령을 모르는 읽기라 한 것)

실전 처리 원칙:
```

## 이견 항목 23: 천간 임수·계수가 갑·을목을 생하는가 (수생목의 천간/지지 구분)

```
- 연월일시를 초년·청년·중년·말년으로 나누는 방식은 대운 체계가 자리 잡기 전의 옛 틀이라 지금 그대로 쓰기 어렵고 일부만 참고한다 (vDNa6ASwjzc@2:05)
- 시주는 말년이 아니라 앞으로 살고 싶은 계획이며, 대운과 생극 기법이 발달한 지금은 궁을 시기의 기준으로 삼을 필요가 없다 (bkhKuDBQg4A@3:10, zDIvORw-sW8)
- 가설: 월지=환경과 틀, 일지=행동 양식, 시지=앞날의 구상이고 해석 순서는 월지→일지→시지→연지다 (xob-4TTcw0s@8:07). 자리별 왕지 해석은 화자가 새 가설이라고 직접 밝혔다 (hRPnhCvj7Mo)

실전 처리 원칙:
→ 29 §4의 영역 표는 바꾸지 않는다. 시지를 말년으로 읽을 때는 확정이 아니라 한 견해임을 밝히고, 대운이 이미 시기를 정하므로 시기 단정에는 쓰지 않는다
→ 시지 신살·관계를 서술할 때 지향하는 삶의 형태 해석을 병기한다. 의뢰인이 노후·말년운을 시주로 물을 때 선운 견해를 참고로 제시하되, 판정·점수에는 쓰지 않는다 (37_sunwoon_layer.md)
```

## 이견 항목 28: 궁합 판정의 기준 — 용신 보충·합충 대조인가, 십성 구조와 관계 방식인가

### 쟁점: 두 사람의 궁합을 오행 보충이나 합충 건수로 가르는가?

```
인연법 일반 (33 §1이 학파 편차가 극심하다고 밝힌 영역):
- 용신법: 내 용신을 보충하는 방향의 상대를 본다 (33 주축, 격국·조후로 정한 용신)
- 일지·띠·일주 대조법: 상대 지지와 내 일지·원국의 합충 관계를 센다 (33은 띠 단독 C~D, 일주 대조 C)
- 본 스킬은 용신 보충을 사람 유형이 아닌 관계 역학으로 옮기고(33 §7 ③) 사람 판정·상대 명조 없는 단정·결혼 단정을 금한다 (33 §1-1)

현대 강의 견해 (선운의 명리터, 후보 — 부족한 오행 보충 3편, 합충 대조 3편):
- 부족한 오행을 채워 줄 사람을 고르는 일은 실행할 수도 의미도 없다. 없는 오행의 사람은 방식이 이해되지 않아 만나지지 않고, 그 오행의 운이 와야 인연이 닿는다 (C-ChQTvQE8k@10:13, NMT5yxBY3vU@33:22, Foc845EYdmU@1:07)
- 두 사람의 명조를 맞대어 합충·원진을 세는 것은 근거가 없고, 합충은 한 사람의 원국 안에서만 일어난다 (6ay4_nJIaRU@28:37, FWDqP-ZZKI0@7:02, kHhugtniau8@1:21:51)
- 궁합은 좋고 나쁨이 아니라 재정·정서·봉양·자녀 중 어느 면에서 어떻게 맞춰 사느냐이고, 재생관(조건·역할의 거래)과 식상생재(상부상조·애정) 같은 구조와 없는 십성의 방식으로 읽는다

실전 처리 원칙:
→ 33의 축별 등급, 금지 목록, 발동×수용 판정은 그대로 둔다. 선운 견해와 33은 사람 판정 금지·합이면 좋다의 반례(33 §6-3)에서 이미 같은 방향이다
→ 33 §6 정합 지지 판정 결과를 낼 때 지지 한 글자로 사람을 거르는 용도가 아니라는 점을 앞에 두고, 상대 명조가 없으면 방향까지만 말한다
→ 용신 오행을 이 오행의 사람을 만나라로 옮기지 않고 관계 역학으로만 옮긴다 (33 §7 ③ 재확인)
→ 의뢰인이 부족한 오행의 상대나 합충 궁합을 직접 물을 때 선운 견해를 참고로 제시한다. 선운 견해는 참고로 병기할 뿐 판정·점수에 쓰지 않는다 (37_sunwoon_layer.md)
```
