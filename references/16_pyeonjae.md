# 자평진전(子平眞詮) — 편재격(偏財格)

> 자평진전 격국론 시리즈 6편.

---

## 1. 정의와 본질

편재격(偏財格)은 **월지 본기가 편재**면 성립한다 — 투출하면 더 맑고, 투출하지 않아도 1순위다. 본기가 불투하고 중기·여기의 편재가 투출했거나, 본기가 불투한 채 월지가 낀 삼합이 다 모여 국이 재 무리가 되면 이 격으로 변할 수 있는 **변화 후보**다 — 원문은 본기가 불투하고 중기가 투출하면 중기가 작주한다고 하고(「不透甲而透丙」), 회국도 격을 바꾼다고 한다(「支全卯未，则化为印」, 논용신변화). 원전은 반합도 국으로 본다(赵知府 丙午 庚寅 丙午 癸巳의 徐注 「寅午化印为劫」 — 寅午 반합. 「甲不透干而会午会戌」은 寅午戌 삼합의 예다) — 스크립트는 삼합이 다 모일 때만 변화 후보를 내므로 반합은 직접 따진다. 본기도 투출했으면 변하지 않는다(「丙生寅月，午戌会劫，而又或透甲，或透壬，则仍为印而格不破」의 「或透甲」 — 「或透壬」은 다른 투간이 격을 지키는 경우다, SKILL 4-1 ⑤). 국의 정·편은 투간으로만 가리고, 투간이 없거나 정·편이 함께 투간하면 스크립트는 '재격(회국 변화 후보)'처럼 무리로 적는다 — 원문의 「化为印」, 徐注의 「伤化为财」「劫化为食伤」처럼 원전도 무리로 부른다. 辰戌丑未월은 잡기 절차(`35_japgi.md`), 건록·양인·월겁 월령은 `34_geonrok_yangin.md`를 먼저 탄다 (SKILL.md 4-1, errata #20).
편재(偏財)란 일간이 음양이 같게 극(剋)하는 오행이다.

| 일간 | 편재 |
|---|---|
| 甲(양목) | 戊(양토) |
| 乙(음목) | 己(음토) |
| 丙(양화) | 庚(양금) |
| 丁(음화) | 辛(음금) |
| 戊(양토) | 壬(양수) |
| 己(음토) | 癸(음수) |
| 庚(양금) | 甲(양목) |
| 辛(음금) | 乙(음목) |
| 壬(양수) | 丙(양화) |
| 癸(음수) | 丁(음화) |

**편재의 본질**: 정재가 성실하게 쌓는 안정적 재물이라면, 편재는 유동적이고 사업적인 재물이다. 투기·무역·사업·대규모 자금의 흐름과 연결된다. 편재는 아버지를 상징하기도 한다.

## 2. 성립 조건과 편재격의 특성

월지 본기가 편재면 편재격이 성립한다. 중기·여기의 편재 투출은 변화 후보이고, 본기와 함께 볼 때는 본기가 먼저다. (옛 서술 "월지 장간 중 투출하면 성립"은 투출 우선 규칙이라 폐기 — errata #20)

편재격은 정재격보다 더 유동적이고 변동이 많은 성질을 가진다. 일간이 강해야 편재를 감당할 수 있다는 점은 정재격과 같다.

**편재격의 특수성**: 편재는 정재보다 규모가 크고 유동성이 높다고 풀이한다(후대의 성정 풀이 — 자평진전은 재를 정·편으로 나누지 않아 격의 길흉 규칙은 정재격과 같다, §7 이견 ①).

## 3. 용신·희신·기신

### 용신

**① 식상(食傷) — 식상생재(食傷生財)**

편재격도 식상이 재를 생하는 구조가 기본 용신이다.

**② 관성(官星) — 재생관(財生官)**

편재가 관성을 생하는 구조. 사업으로 권력을 얻는 형상이다. 조건은 정재격과 같다 — 신강하고 상관이 드러나지 않고 칠살이 섞이지 않아야 한다(「有财旺生官者，身强而不透伤官，不混七煞，贵格也」). 신약한데 관이 드러나면 깨진다(「身弱透官，即为破格」).

**③ 식신제살 후 재생살 방지**

칠살이 있는 편재격에서 식신이 살을 제어하고 재성이 살을 생하지 않도록 구조를 잡아야 한다.

### 기신

**① 겁재(劫財) — 겁재탈재**

재가 가볍고 비겁이 무거우면 깨진다(「财轻比重」) — 정재격과 같다(재는 정·편을 나누지 않는다 — 「财与印不分偏正」). 막는 것도 같다 — 식상이 겁재를 화하거나(「财逢劫而透食以化之」) 관이 누른다(「生官以制之」).

**② 칠살 + 재성의 악순환**

칠살격이 아닌 편재격에서 칠살이 있으면, 편재가 칠살을 생하여 칠살이 더 강해지는 악순환이 발생한다(「财透七煞，财格败也」). 다만 살을 합하거나 제하면 귀격이다(「有财带七煞者，或合煞存财，或制煞生财，皆贵格也」, §4 ③).

**③ 식상 — 재가 관을 쓸 때**

재왕생관은 상관이 드러나지 않아야 한다(「不透伤官」, 带忌 「财旺生官而又逢伤逢合」). 식신도 관을 친다(「财旺生官，露食则杂，食能破格也」, 논사길신능파격). 관 없이 식상을 쓰면 정재격과 같다 — 식신은 신강·관 불투일 때(재용식생), 상관은 재가 왕하지 않고 비겁이 강할 때 쓰고(「财不甚旺而比强」), 재가 왕하고 겁재가 없는데 상관이 드러나면 불리하다(「财旺无劫而透伤，反为不利」).

## 4. 성격(成格)

### 유형 ① 편재용식(偏財用食)

식상이 편재를 생하는 구조. 사업 능력(식상)으로 큰 재물(편재)을 만드는 형상. 신강하고 관이 드러나지 않아야 한다(「身强而不露官」 — 신약에 관이 드러나면 「透官身弱，则格坏矣」).

### 유형 ② 편재생관(偏財生官)

편재가 관성을 생하여 재관쌍미를 이루는 구조. 신강·상관 불투·칠살 불혼이 조건이다(§3 용신 ②). 재왕생관에 상관이나 합이 오면 带忌다(「财旺生官而又逢伤逢合」).

### 유형 ③ 재대칠살 — 제살생재·합살존재

편재격에 칠살이 있을 때 식신으로 살을 제어하거나(제살생재 — 李御史 〔庚辰 戊子 戊寅 甲寅〕는 子월 정재격이지만 재는 정·편을 나누지 않으므로 같다, 15번 §7) 살을 합해 묶으면(합살존재) 살의 위협이 제거되고 재의 기운이 온전해진다. 毛状元 〔乙酉 庚辰 甲午 戊辰〕은 辰월에 戊土 편재가 투출한 잡기 편재격으로, 乙木이 庚金 칠살을 합한다 — 「如毛状元命，乙酉、庚辰、甲午、戊辰，合煞存财也」(논재). 徐注는 이를 午중 丁火의 제살로 본다(「所谓合煞存财，义殊未当…丁火扬威，制煞为用」).

## 5. 패격(敗格)

### 유형 ① 겁재탈재

정재격과 동일한 패격 구조다.

### 유형 ② 재성생살(財星生殺)

편재격에 칠살이 있고 편재가 칠살을 생하는데 합살·제살이 없으면, 살이 더욱 강해져 일간을 위협한다.

## 6. 편재격 vs 정재격 비교

| | 정재격 | 편재격 |
|---|---|---|
| 재물의 성질 | 성실, 안정, 보수적 | 유동, 사업, 투기 |
| 규모 | 소~중규모 | 중~대규모 |
| 겁재 위협 | 같다(겁재탈재) | 같다(겁재탈재) |
| 아버지 상징 | 정재(처·재물) | 편재(아버지) |
| 성격 키워드 | 성실, 관리 | 사업가, 유동성 |

---

## 7. 학파 간 이견

**이견 ①** 편재와 정재의 경계: 자평진전은 재와 인을 정·편으로 나누지 않고 한 격으로 논한다(「财与印不分偏正，同为一格而论之」, 논인수). 정·편의 성정 차이(유동 재물·부친 등)를 격의 길흉에 반영하는 것은 후대 학파의 견해다. 겁재도 같다 — 재용식생에 신강하고 관이 드러나지 않으면 비겁 하나는 오히려 유정하다(「略带一位比劫，益觉有情」, 杨待郎 〔壬寅 壬寅 庚辰 辛巳〕 — 寅 본기 甲은 庚에게 편재라 실은 편재격이다).

**이견 ②** 편재의 아버지 상징: 자평진전은 편재를 아버지로 보는 까닭을 직접 설명한다 — 「若偏财受我克制，何反为父？偏财者，母之正夫也，正印为母，则偏财为父矣」(논궁분용신배육친). 徐注는 甲 일간이면 癸가 어머니, 戊가 아버지(戊癸合)라 풀고, 음간은 양간을 따른다(「五阴干从阳干取」)고 한다. 다만 이것은 육친 배정이고, 격의 길흉은 정·편을 나누지 않는다(이견 ①). 편재의 성정(유동 재물·활동성 등)을 따로 강조하는 것은 후대 학파의 견해다.

## 8. 편재격 핵심 요약

성격: 식상생재 또는 재관쌍미
패격: 겁재탈재(「财轻比重」) 또는 재투칠살(「财透七煞」)
구격: 식상이 겁재를 화함(「财逢劫而透食以化之」), 관성이 겁재 제어(「生官以制之」), 식신제살·합살(재대칠살 — 「或合煞存财，或制煞生财」)
