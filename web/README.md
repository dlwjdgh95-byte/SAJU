## `unui-sigantable.html` — 운의 시간표

이번 주·다음 주, 이번 달·다음 달, 올해·내년의 운을 **12신살·십이운성·지지 관계**로 읽는 만세력 지면.
Claude의 Artifact로 게시해 쓰며, 매일 아침 Routine이 `DAILY` 블록만 새로 써서 같은 URL에 재게시한다.

> ⚠️ 이 폴더는 **스킬 본문이 아니다.** 스킬로 업로드할 때는 `SKILL.md`·`references/`·`scripts/`만 필요하다.

### 운 점수 (references/28 §5·§8)

5축(격국·조후·합충·감당력·왕쇠신살)을 층위 비중으로 채점해 0~100 + 밴드로 낸다.
용신은 **억부 + 조후 2축의 자동 판정**이다 — 격의 성패·병약론·종격은 판정하지 않는다.
28번 §7의 손채점 18건 대조: 평균오차 9.1 · 밴드 일치 11/18 · 상관 0.69.
표본이 한 명조뿐이라 더 맞추려는 조정은 과적합이므로 하지 않는다.

### 층위 결합 (references/31 §6)

한 층위만 보면 안 보이는 것을 잡는다.

- **초점 자리** — 한 원국 궁에 2개 이상 층위가 걸릴 때. 강도 = Σ(층위 비중 × 관계 세기), 비중은 대운 25 · 세운 12 · 월운 5 · 일운 3. 대운이 8배 무거워 순위가 잘 안 바뀌므로 **대운 제외 점수**를 따로 표시한다
- **삼합·방합 완성** — 운이 들어와 3자가 채워진 것만. 원국 글자만으로 이미 선 국은 세지 않는다. 출처 층위를 반드시 표기하고 "그 운이 지나면 풀린다"를 말한다
- **복음·반음**, **운끼리의 관계 6쌍**, **여러 층위가 공망지에 걸리는 경우**

### 검증

JS 엔진은 `scripts/saju_calc.py`와 30개 명조(1920~2044년생, 절입 경계·자시 경계 포함)에서
**사주 4기둥 · 대운수 · 대운 첫 간지 · 12신살 · 공망**이 전부 일치함을 교차확인했다.

```bash
node - <<'EOF'
const fs=require('fs');
const html=fs.readFileSync('web/unui-sigantable.html','utf8');
const src=html.slice(html.indexOf('<script>')+8, html.indexOf('/* ══ 렌더'));
const E=new Function(src+'; return {buildNatal,sinsal12,unseong,relationsTo,dayPillar,kmin,nowKd};')();
console.log(E.buildNatal({date:'1995-10-29',time:'06:30',timeKnown:true,gender:'M'}).pillars.join(' '));
EOF
```

> 페이지의 `const` 선언은 그냥 `eval`로는 밖으로 새지 않는다. 위처럼 `new Function`으로 감싸 필요한 것만 돌려받는다.

### 갱신 구조

```
DAILY = {
  for, profile, title, body, act,   ← 필수 5필드. 매일 아침 이 블록만 교체된다
  rev, sig,                          ← 선택. sig = 글 쓸 당시의 4층 서명
  layers, stack                      ← 선택. 없으면 각각 독립적으로 엔진이 채운다
}
```

**명식판과 사실 스트립(간지·십신·12신살·십이운성·관계)은 언제나 엔진 계산값이다. `DAILY`에서 읽지 않는다.**
`DAILY`는 문체만 제공한다. 그래서 사람 글이 하루 밀렸거나 대운 경계를 넘겨도 숫자가 틀리는 일은 없다.

| 상황 | 결과 |
|---|---|
| `for`가 오늘이 아님 | 층위 서술·결합 문단을 엔진이 채우고 사유를 고지 |
| 다른 명식을 입력해 둠 | 위와 동일 |
| `sig` 불일치(대운·절기 경계를 넘김) | 층위 서술만 엔진으로 강등 |
| 선택 필드가 없는 구 버전 | 정상 동작 — 엔진이 전부 채운다 |

⚠️ **`DEFAULT_PROFILE`과 `DAILY.profile`은 반드시 함께 바꾼다.** 한쪽만 바꾸면 프로필 대조가 영원히 어긋나
사람이 쓴 아침 글이 화면에 뜨지 않는다.

### ⚠️ 예약 작업과의 계약

매일 아침 갱신 Routine이 이 파일에서 엔진을 잘라 쓴다. 셋 중 하나라도 깨지면 갱신이 **조용히** 실패한다.

1. **`/* ══ 렌더` 마커 문자열을 바이트 단위로 유지.** 신규 엔진 코드는 반드시 이 마커 **위**에 둔다
2. Routine이 구조분해하는 이름(`buildNatal`·`relationsTo`·`sinsal12`·`unseong`·`SINSAL_DESC` 등)을 **개명·삭제하지 않는다.** `relationsTo`의 `pos`/`zhi`/`rel`/`weight` 필드도 마찬가지 — 추가는 되고 개명은 안 된다
3. **인라인 `<script>` 태그는 1개.** 주석 안에도 그 문자열을 쓰지 않는다 (Routine의 문법 검사가 `split`으로 잘라낸다)

생년월일시는 브라우저 `localStorage`에만 저장되며 어디로도 전송되지 않는다.
